# ТЗ: плитки подкатегорий с фото в «Кухнях» и «Шкафах»

Составлено 27.09.2026 в облаке, **на сайт не залито**. Задача №2 в `TASKS-board.md`.
Делать в локальной сессии с браузером (админка `/adminmeb.php`).

**Цель.** Сейчас на страницах «Кухни» (`/mebel-dlya-doma-ru/kuhni/`) и «Шкафы» (URL уточнить)
3 подкатегории выводятся текстовым списком. Нужны плитки с фото:

| Кухни | Шкафы |
|---|---|
| Кухни на заказ | Шкафы-купе |
| Кухни по стилям | Шкафы распашные |
| Кухни модульные Фабричные | Шкафы модульные фабричные |

Сетка: 3 в ряд на ПК, 2 на планшете, 1 на телефоне. Фото + подпись, эффект при наведении.

> Не путать с `TZ-poryadok-kartochek-kuhni-shkafy.md`: там порядок и фото плиток
> на **уровень ниже** («Современные», «Массив» и т. п.), там плитки с фото уже есть.

## Шаг 0. Найти, откуда берётся текстовый список (5 минут, обязательно)

От ответа зависит вариант. Проверять по порядку:

1. **Описание категории.** Товары → Категории → «Кухни» → вкладка «Общее» → поле «Описание»,
   кнопка «Источник» (HTML). Если там ссылки `<a href=…>Кухни на заказ</a>` — список вбит руками.
   → Удалить эти ссылки из описания (сначала скопировать HTML в файл-бэкап), делать Вариант А или Б.
2. **У подкатегорий просто нет картинок.** Штатный шаблон CS-Cart (`views/categories/view.tpl`)
   выводит подкатегории **картинками, если у них есть изображение, и текстом, если нет**.
   Открыть «Кухни на заказ» → «Изображения»: если пусто — скорее всего причина в этом.
   → **Вариант А0**: просто загрузить 6 фото (раздел «Фото» ниже). Возможно, больше ничего не нужно.
3. **Отдельный блок.** На витрине: правый клик по списку → «Просмотреть код» (DevTools).
   Подняться вверх по дереву до обёртки блока — у CS-Cart это `div` с классами вида
   `ty-wysiwyg-content`, `ty-subcategories`, `ty-menu`, `ut2-…` и `id="…_NNN"` (NNN — номер блока).
   Затем Дизайн → Макеты → вкладка страницы **«Категории»** → найти блок с этим номером/названием
   (у блока шестерёнка → в заголовке окна видно ID и тип).
4. **Режим правки шаблонов** (если не нашли): Дизайн → Шаблоны → кнопка «Режим редактирования
   шаблонов» (или верхняя панель админки → «Режим настройки» → «Редактирование шаблонов»).
   На витрине при наведении на список покажется путь `.tpl`. После проверки режим **выключить**.

Записать в PROGRESS, что нашли: описание / нет картинок / блок №… / шаблон `…tpl`.

## Вариант А0. Картинки подкатегориям (если список текстовый из-за отсутствия фото)

1. Товары → Категории → раскрыть «Кухни» → «Кухни на заказ» → раздел «Изображения» →
   загрузить фото (см. ниже), заполнить **Alt** (например «Кухня на заказ в Пятигорске —
   Мебель Inside»). Сохранить. Повторить для 6 подкатегорий.
2. Сброс кэша: `https://mebelinside.ru/adminmeb.php?cc&ctpl`.
3. Проверить страницу в инкогнито. Если плитки появились, но мелкие или не 3 в ряд — добавить CSS
   из Варианта Б (блок `<style>`) через HTML-блок, либо перейти к Варианту А/Б.

Откат: удалить загруженные изображения у подкатегорий.

Также глянуть: Дизайн → Темы → UniTheme2 → **«Настройки темы»** → раздел «Категории» — у
UniTheme2 бывает опция вида «Показывать подкатегории: списком / с изображениями». Если есть —
переключить на «с изображениями» (записать старое значение для отката). Не проверено: из облака
админка недоступна.

## Вариант А. Штатный блок «Категории» с сеткой-картинками

Без правки файлов. Работает, если в списке шаблонов блока есть сетка с картинками.

1. Сначала загрузить 6 фото подкатегориям (как в А0, п. 1).
2. Дизайн → Макеты → активный макет UniTheme 2 (Advanced) → вкладка **«Категории»**.
3. В контейнере «Содержимое» (Content) **над** блоком «Основное содержимое» → «+» у сетки →
   «Добавить блок» → «Создать новый блок» → тип **«Категории»**.
4. Настройки блока:
   - Название: `MI плитки подкатегорий`, «Показывать заголовок» — нет.
   - **Шаблон**: «Сетка категорий с несколькими колонками» (`categories_multicolumn_list.tpl`)
     или похожий шаблон UniTheme2 с картинками (`AB: …` / «… сетка / с изображениями»).
     Колонок: **3**.
   - **Заполнение**: «Подкатегории» (дочерние текущей категории). Если это заполнение просит
     выбрать родителя — вместо него «Вручную» и сделать **2 блока**: «Кухни» (3 подкатегории) и
     «Шкафы» (3 подкатегории).
5. Показывать только в «Кухнях» и «Шкафах»: у блока кнопка «Статус» / «Выкл. для…» →
   выключить везде, кроме этих двух категорий. Либо: Товары → Категории → «Кухни» →
   вкладка **«Макеты»** → включить блок здесь (и в «Шкафах»), глобально блок выключен.
6. Старый текстовый список убрать (по итогам Шага 0): ссылки из описания / выключить старый блок
   для этих двух категорий. Если список рисует «Основное содержимое» — скрыть CSS (см. Б, п. 4).
7. `?cc&ctpl`, проверить.

Минус: штатная сетка не всегда даёт ровно 3/2/1 и hover. Если выглядит плохо — Вариант Б
(тот же блок, только шаблон свой).

Откат: удалить блок `MI плитки подкатегорий` в Макетах, вернуть старый блок/описание.

## Вариант Б. Свой шаблон блока + CSS (рекомендую)

Свой шаблон для блока типа «Категории». CS-Cart сам подхватывает `.tpl` из папки
`blocks/categories/` темы, если в первой строке есть комментарий `block-description`.
CSS лежит внутри шаблона, поэтому выводится **только там, где стоит блок** (Кухни/Шкафы) —
заодно этим же CSS можно скрыть старый список только на этих страницах.

### Б.1. Файл

**Путь на сервере:**
`~/public_html/design/themes/abt__unitheme2/templates/blocks/categories/mi_subcat_tiles.tpl`

**Путь в админке:** Дизайн → Шаблоны → `abt__unitheme2` → `templates` → `blocks` → `categories` →
«Создать файл» → `mi_subcat_tiles.tpl`.
(Если в редакторе админки создание файла не работает — через Файловый менеджер Timeweb,
тот же путь. Про особенности Monaco-редактора Timeweb см. журнал 13.09.)

**Код файла целиком:**

```smarty
{** block-description:mi_subcat_tiles **}
{if $items}
<style>
/* MI 2026-09-27: плитки подкатегорий Кухни/Шкафы */
.mi-subtiles{display:grid;grid-template-columns:repeat(3,1fr);gap:24px;margin:0 0 32px;padding:0;list-style:none}
.mi-subtiles__item{margin:0;padding:0}
.mi-subtiles__link{display:block;position:relative;overflow:hidden;border-radius:12px;background:#f2f0ec;
  color:#222;text-decoration:none;box-shadow:0 2px 10px rgba(0,0,0,.08);transition:box-shadow .25s,transform .25s}
.mi-subtiles__img{display:block;width:100%;aspect-ratio:4/3;object-fit:cover;transition:transform .45s ease}
.mi-subtiles__noimg{display:block;width:100%;aspect-ratio:4/3;background:#e8e4dd}
.mi-subtiles__title{display:block;padding:14px 16px;font-size:18px;font-weight:600;line-height:1.3;text-align:center;background:#fff}
.mi-subtiles__link:hover,.mi-subtiles__link:focus-visible{box-shadow:0 8px 24px rgba(0,0,0,.16);transform:translateY(-3px)}
.mi-subtiles__link:hover .mi-subtiles__img{transform:scale(1.05)}
.mi-subtiles__link:hover .mi-subtiles__title{color:#b8860b}
@media (max-width:1023px){.mi-subtiles{grid-template-columns:repeat(2,1fr);gap:16px}}
@media (max-width:575px){.mi-subtiles{grid-template-columns:1fr;gap:14px}.mi-subtiles__title{font-size:16px}}
/* скрыть старый текстовый список — только там, где стоит этот блок.
   Селектор сверить в DevTools (Шаг 0, п. 3) и при необходимости заменить. */
.ty-subcategories{display:none!important}
</style>
<ul class="mi-subtiles">
{foreach $items as $cat}
  {if $cat.main_pair}
    {$pair = $cat.main_pair}
  {else}
    {$pair = $cat.category_id|fn_get_image_pairs:"category":"M":true:true}
  {/if}
  {if $pair}{$img = $pair|fn_image_to_display:800:600}{else}{$img = []}{/if}
  <li class="mi-subtiles__item">
    <a class="mi-subtiles__link" href="{"categories.view?category_id=`$cat.category_id`"|fn_url}">
      {if $img.image_path}
        <img class="mi-subtiles__img" src="{$img.image_path}" width="800" height="600"
             alt="{$img.alt|default:$cat.category}" loading="lazy">
      {else}
        <span class="mi-subtiles__noimg"></span>
      {/if}
      <span class="mi-subtiles__title">{$cat.category}</span>
    </a>
  </li>
{/foreach}
</ul>
{/if}
```

Цвет hover `#b8860b` (золотистый) — заменить на фирменный акцент сайта, если отличается.

### Б.2. Блок

1. Загрузить 6 фото подкатегориям (как в А0, п. 1).
2. Сброс кэша `?cc&ctpl` — иначе новый шаблон не появится в списке.
3. Дизайн → Макеты → вкладка **«Категории»** → контейнер «Содержимое», над «Основное содержимое» →
   «Добавить блок» → «Создать новый блок» → тип **«Категории»**:
   - Название `MI плитки подкатегорий`, заголовок не показывать;
   - **Шаблон**: `mi_subcat_tiles` (так он называется в списке);
   - **Заполнение**: «Подкатегории» (текущей категории). Если просит родителя — «Вручную»,
     два блока: `MI плитки — Кухни` и `MI плитки — Шкафы`, по 3 подкатегории, порядок как в таблице вверху;
   - Настройки блока (шестерёнка) → «Обёртка» пустая, «CSS-класс» можно не заполнять.
4. Показать только в двух категориях: блок глобально выключен, включён у «Кухни» и «Шкафы»
   (кнопка «Статус» блока → выбор категорий, либо вкладка «Макеты» в карточке категории).
   Важно: включать **только у самих «Кухонь» и «Шкафов»**, не у дочерних — иначе правило
   `.ty-subcategories{display:none}` спрячет штатные плитки уровнем ниже.
5. Старый список: если он в описании категории — убрать ссылки из описания (бэкап HTML);
   если отдельный блок — выключить его для этих двух категорий; если его рисует
   «Основное содержимое» — его прячет строка `.ty-subcategories{…}` в CSS.
   В DevTools проверить реальный класс обёртки старого списка (у UniTheme2 может быть
   `ut2-subcategories` / `ty-subcategories-block` и т. п.) и подставить его в эту строку.
6. `?cc&ctpl`.

### Б.3. Если плитки выводятся без фото

`fn_get_image_pairs` / `fn_image_to_display` — штатные функции CS-Cart 4.x. Если картинок нет,
а у подкатегорий они загружены: проверить, что фото загружено в «Изображение» (основное),
а не в «иконку»; как запасной путь заменить строку с `fn_image_to_display` на штатный инклюд:

```smarty
{include file="common/image.tpl" images=$pair image_width=800 image_height=600 no_ids=true class="mi-subtiles__img"}
```

## Проверка (для любого варианта)

- [ ] «Кухни» и «Шкафы»: 3 плитки с фото, подписи верные, ссылки ведут в нужные подкатегории
- [ ] Старого текстового списка нет (ни сверху, ни снизу страницы)
- [ ] ПК (≥1024 px) — 3 в ряд; планшет (DevTools, 768 px) — 2; телефон (375 px) — 1
- [ ] Hover: плитка приподнимается, фото чуть увеличивается
- [ ] Уровнем ниже (например «Кухни по стилям») штатные плитки не пропали
- [ ] Другие категории (Матрасы, Прихожие…) — без изменений
- [ ] Проверено в инкогнито и с телефона после `?cc&ctpl`
- [ ] Скриншоты «до/после» — в PROGRESS

## Фото: 6 штук

| # | Подкатегория | Что на фото |
|---|---|---|
| 1 | Кухни на заказ | наша лучшая светлая современная кухня целиком (прямые фасады/рамка, дневной свет) |
| 2 | Кухни по стилям | другая наша кухня, другого стиля/цвета, чем №1 (например неоклассика светлая) |
| 3 | Кухни модульные Фабричные | фабричная модульная кухня (фото поставщика или из наших товаров-фабрик) |
| 4 | Шкафы-купе | купе до потолка, зеркало/стекло, тонкий профиль |
| 5 | Шкафы распашные | распашной шкаф с прямыми фасадами, светлый |
| 6 | Шкафы модульные фабричные | фабричный модульный шкаф |

**Требования:**
- Формат **4:3, 1200×900 px** (минимум 800×600). Шаблон режет превью до 800×600 по `object-fit:cover`.
- JPG, качество ~80, **до 200 КБ**.
- Мебель по центру, по краям ~10% запаса (на телефоне и при hover край подрезается).
- Все 6 — в одной яркости и тоне, светлые, без людей и мусора (правила улучшения через ChatGPT —
  как в `TZ-poryadok-kartochek-kuhni-shkafy.md`: только свет/баланс/резкость, мебель не менять).
- Имена файлов: `podkat-kuhni-na-zakaz.jpg`, `podkat-kuhni-po-stilyam.jpg`,
  `podkat-kuhni-modulnye.jpg`, `podkat-shkafy-kupe.jpg`, `podkat-shkafy-raspashnye.jpg`,
  `podkat-shkafy-modulnye.jpg`.
- Alt у каждой: «<Подкатегория> — Мебель Inside, Пятигорск» (без «матрасов», см. 11.09).

## Порядок работы для локальной сессии (кратко)

1. Шаг 0: найти источник списка → записать.
2. Подготовить и загрузить 6 фото в подкатегории.
3. Если плитки появились сами (А0) — проверить и закончить.
4. Иначе Вариант Б (файл + блок). Если нет доступа к созданию файла — Вариант А.
5. Проверка по чек-листу, скриншоты, строка в JOURNAL, статус №2 в `TASKS-board.md`,
   PROGRESS по шаблону из `templates/`.
