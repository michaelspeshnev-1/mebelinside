# Видео-движок «Мебель Inside» (локальный, без платных API)

Кладёте в папку `input/` видео или запись голоса. Движок сам расшифровывает речь, режет ролик на сцены,
рисует заголовок, субтитры и призыв с контактами, подмешивает музыку, собирает MP4 и проверяет его.
Всё работает на вашем компьютере.

**Результат: `final/<имя-файла>.mp4`** и рядом отчёт приёмки `final/<имя-файла>.report.md`.

## Быстрый старт на Windows

1. Распакуйте архив, **откройте папку, в которой лежит `package.json`** (не папку выше).
2. Дважды щёлкните `SETUP-WINDOWS.cmd`. Если не хватает программ, он напечатает команды `winget install ...`; выполните их в PowerShell, закройте окно и запустите снова.
3. Проверка: в PowerShell из этой папки `npm run demo`. Автозапуск: `powershell -File scripts\install-autostart.ps1`.

## Быстрый старт (macOS или Linux)

```bash
brew install node python ffmpeg        # macOS (Ubuntu: sudo apt-get install nodejs npm python3 python3-venv ffmpeg)
npm run setup                          # пакеты, Python-окружение, модель Whisper, диагностика
npm run demo                           # проверочный ролик -> final/demo.mp4
```

Если что-то не так: `npm run doctor` — скажет по-русски, что именно и как исправить.

## Как это работает «само»

```bash
npm run watch                          # следит за input/; положили файл — через несколько минут ролик в final/
bash scripts/install-autostart.sh      # чтобы наблюдатель запускался сам при входе в систему (macOS/Linux)
```

Логи: `logs/`. Состояние: `brief/.watch-state.json` (обработанный файл повторно не делается, пока вы его не замените).
Ошибка на одном файле не останавливает остальные: она записывается в лог человеческим языком.
Настройки по умолчанию — `engine.config.json` (формат `vertical` 1080×1920 для рилсов, тема `mebel-inside`, музыка из `assets/music/`).

## Что положить и куда

| Что | Куда |
|---|---|
| видео из цеха/с объекта или запись голоса (mp4, mov, m4a, mp3, wav…) | `input/` |
| фото готовых работ (png, jpg, webp) | `assets/broll/` |
| логотип (необязательно) | `assets/logo.png` |
| фоновая музыка — **только свой трек или с чистыми правами** | `assets/music/` |
| свой заголовок/CTA/подборка фото для ролика | `brief/<имя>.hints.json` |

Пример `brief/kuhnya.hints.json`:

```json
{ "title": "Угловая кухня без потерь места", "broll": ["assets/broll/kuhnya-1.jpg", "assets/broll/kuhnya-2.jpg"], "cta": "Рассчитаем вашу кухню" }
```

## Три режима

1. **Видео со спикером/из цеха**: спикер + субтитры → крупный заголовок → B-roll (ваши фото) → спикер → призыв (CTA) с контактами.
2. **Только голос + фото (без лица в кадре)**: фото слайд-шоу с плавным движением → заголовок → фото → призыв. Подходит под «снимать себя не хочу».
3. **Вертикаль/горизонталь/квадрат**: `--format vertical|landscape|square`, свой размер — `--size 1080x1920`. Безопасные зоны под интерфейс Reels/Shorts зашиты в тему.

## Фирменная тема (слой 1: «Тема»)

Файл `theme/mebel-inside.json`: цвета (графит + тёплый акцент), безопасные зоны для вертикали и горизонтали,
название и контакты в CTA, параметры звука, текст призыва. Меняйте файл — меняется весь стиль. Цвета подобраны под
описание сайта (белый/серый/графит, спокойный премиальный тон); если у бренда есть точные фирменные цвета, впишите их в `colors`.
Архитектура по руководству: **тема + композиция (папка `remotion/`) + JSON-план (`brief/*.plan.json`) = MP4**.

## Музыка, которую «нажимает» голос (sidechain)

Если в `assets/music/` лежит трек (или указана опция `--music путь`), FFmpeg приглушает музыку под речью
(`sidechaincompress` + `amix`). Параметры из руководства, в `theme/mebel-inside.json`, блок `audio`:
`gainDb −17`, `thresholdDb −28`, `ratio 8`, `attackMs 5`, `releaseMs 300`. После сборки приёмка измеряет, что в речи голос
громче приглушённой музыки не менее чем на 6 дБ.

## Приёмка в три контура

После каждого ролика движок сам проверяет и пишет `final/<имя>.report.md`:

* **Смысл**: все слова расшифровки в субтитрах, хук в первые 3 секунды, есть заголовок и призыв с контактами, **на экране нет цен**.
* **Картинка**: безопасные зоны, нет мелькающих сцен, использованы ваши фото, кадры сцен не чёрные и различаются.
* **Техника**: параметры ffprobe (H.264, AAC, размер, частота кадров, длительность), faststart, **полное декодирование без ошибок**,
  синхрон звука и картинки, звук слышен и не клиппирует, музыка не перекрывает голос.

Пункты с значком 👁 машина проверить не может (красота, правильность терминов): их смотрите вы.

## Команды

```bash
npm run run -- input/мой-ролик.mp4                    # один ролик
npm run run -- input/голос.m4a --format vertical      # голос + ваши фото
npm run run -- input/мой-ролик.mp4 --plan-only        # только план, без рендера
npm run run -- input/мой-ролик.mp4 --plan brief/мой-ролик.plan.json   # рендер по вашему (правленому) плану
npm run validate-plan -- brief/мой-ролик.plan.json    # проверка плана без рендера
npm run verify -- final/мой-ролик.mp4 --plan brief/мой-ролик.plan.json
npm run help
```

Промпты для Claude под ваши типы роликов: `docs/PROMPTS.md`.

## Папки

`input/` исходники (движок сюда **никогда не пишет**) · `transcript/` звук и расшифровка · `brief/` планы и подсказки ·
`assets/` фото, музыка, логотип · `previews/` быстрые превью и кадры сцен · `renders/` картинка без звука (промежуточный файл) ·
`final/` готовое · `theme/` фирменные темы · `models/` модели Whisper · `logs/` журналы автозапуска.

## Про распознавание речи (важно)

* **Основной движок — faster-whisper.** Модель скачивает `npm run setup` (≈460 МБ, один раз) либо вручную:
  `.venv/bin/python scripts/download-model.py small`. Для русского берите `small` и больше.
* **Пока модели нет**, включается запасной офлайн-движок pocketsphinx: **только английский** и заметные ошибки в словах.
  Тайминги точные, текст приблизительный. Отчёт приёмки в таком случае прямо требует проверить субтитры глазами.
* **Демо в этой сборке сделаны запасным движком**, поэтому английские субтитры в них местами неточные.
  Русский текст в демо — это только заголовок и призыв из темы.

## Версии

Все зависимости зафиксированы: `package.json` + `package-lock.json` (Node), `requirements.txt` + `requirements.lock.txt` (Python).
Проверено на Ubuntu 24.04, Node 22, FFmpeg 6.1, Python 3.13, Remotion 4.0.532. На macOS не запускалось.

## Чего здесь нет — и почему

* **ElevenLabs** (озвучка из текста) — платный сервис, вы просили без платных API.
* **Pexels** (стоковый B-roll) — не подключён: сеть этой среды его не пропускала, проверить нельзя; по смыслу вашему бизнесу нужнее собственные фото работ.
* **Tesseract, Playwright, @remotion/transitions** — необязательные пункты руководства; переходы (плавные смены) сделаны собственным кодом.
* **Автопоиск лица (OpenCV)** — готов (`--face`), но на реальном человеке не проверялся: тестовый «спикер» — рисунок.
* Заголовок подбирается простым правилом из речи; точный лучше задать в `hints.json`.
* Движок не вырезает паузы и не режет длинную запись на серию — это делает Claude отдельным шагом по вашей просьбе (см. `docs/PROMPTS.md`).
