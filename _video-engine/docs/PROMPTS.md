# Промпты для «Мебель Inside»

Принцип: **человек решает → агент (Claude) режиссирует → движок исполняет.**
Вы говорите, что хотите, Claude правит план/подсказки и запускает движок, движок рисует и проверяет.

Правила вашего контента, которые уже зашиты в проверки: **без цен на экране**, экспертный тон, премиальная подача,
по возможности **без лица в кадре** (голос + фото работ или видео из цеха).

Куда класть материалы:

| Что | Куда |
|---|---|
| видео из цеха/с объекта, запись голоса (m4a, mp3, wav) | `input/` |
| фото готовых работ для B-roll | `assets/broll/` |
| логотип (по желанию) | `assets/logo.png` |
| фоновая музыка (свой трек без чужих прав) | `assets/music/` |

Если запущен `npm run watch` — достаточно положить файл в `input/`, остальное произойдёт само (результат в `final/`).

---

## 1. Рилс из голосового (без лица) — основной формат

> В input/ лежит моё голосовое `kuhnya-gluhaya-uglovaya.m4a`. В assets/broll/ фото этой кухни. Сделай рилс 9:16 с субтитрами, заголовком и призывом в конце. Заголовок: «Угловая кухня без потерь места». Музыку возьми из assets/music.

Claude создаст `brief/kuhnya-gluhaya-uglovaya.hints.json` (`title`, `broll`), запустит `npm run run -- input/kuhnya-gluhaya-uglovaya.m4a --format vertical`.

## 2. Ролик со съёмкой из цеха

> Сделай ролик из input/cex-sborka.mp4: вертикальный, субтитры по словам, в начале заголовок о том, что мы делаем, в конце призыв. Лицо не показывать — кадрируй на руки/станок.

(Автопоиск лица `--face` работает для людей в кадре; для «без лица» оставьте центр кадра или правьте `focusX` в плане.)

## 3. Сокращение длинного видео

> Возьми input/obzor-obekta.mp4, убери паузы и повторы и оставь главное минут на 1. Покажи план до рендера.

Сейчас движок **не режет** исходник (сцены накладываются на целое видео). Для сокращения Claude сперва готовит вырезку FFmpeg-ом в `input/` (оригинал не меняется), затем делает ролик. Это нужно просить явно.

## 4. Разбор «экспертный совет + кейс» (формат Дзена/Telegram)

> Из моего голосового про выбор фурнитуры сделай горизонтальный ролик 16:9. Заголовок: «Как не ошибиться с направляющими». Фото из assets/broll/yashchiki. В субтитрах следи за терминами: М'АртБокс, доводчик, направляющие.

`--format landscape`. Термины проверьте глазами в приёмке: Whisper может исказить названия.

## 5. Вертикализация готового горизонтального видео

> Переведи input/obzor-kuhni.mp4 в 9:16. Центр кадра — на кухонном гарнитуре.

`npm run run -- input/obzor-kuhni.mp4 --format vertical`, при необходимости Claude поправит `focusX` в плане.

## 6. B-roll: подбор фото из портфолио

> Для ролика про шкафы-купе выбери из assets/broll/ только снимки шкафов и гардеробных и поставь их в B-roll в порядке рассказа.

Claude перечислит файлы в `hints.broll` (список). Подбор «по смыслу» делает Claude глазами по фото, не движок.

## 7. Субтитры с акцентом

> Пересобери субтитры: выдели ключевые слова (материал, фурнитура, срок) цветом.

Текущая версия подсвечивает слово, которое звучит сейчас. Выделение ключевых слов — доработка по запросу.

## 8. Музыка и микс

> Подбери микс: музыка тише под голосом. Сейчас кажется громковато.

Параметры в `theme/mebel-inside.json`, блок `audio`: `gainDb` (общая громкость музыки), `thresholdDb` (порог срабатывания по голосу),
`ratio` (сила приглушения), `attackMs` (как быстро музыка уходит), `releaseMs` (как быстро возвращается). Приёмка измеряет запас голоса над музыкой.

## 9. Авторская версия по референсу

> Вот ролик конкурента как референс по ритму и подаче (без копирования). Сделай свою версию из моих материалов в нашем стиле.

Claude опишет ритм референса словами и подстроит раскладку сцен в плане. Чужие кадры, музыку и тексты не берём.

## 10. Серия рилсов из длинной записи

> Из input/razbor-30-minut.m4a нарежь 5 рилсов по 40–50 секунд, каждый про одну мысль.

Claude режет запись по смысловым паузам на отдельные файлы в `input/` (оригинал цел), и каждый становится своим роликом.

## Что сказать Claude после готового ролика

> Покажи отчёт приёмки `final/<имя>.report.md` и перечисли, что мне нужно посмотреть глазами (👁).

Три контура: **смысл** (текст, хук, призыв, нет цен), **картинка** (безопасные зоны, сцены, фото), **техника** (полное декодирование, синхронность звука и картинки, музыка не перекрывает голос).
