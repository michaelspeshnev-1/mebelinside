  Нашёл через Файловый менеджер Timeweb: `app/addons/ab__landing_categories/func.php`,

  `design/themes/abt__unitheme2/templates/addons/ab__landing_categories/hooks/categories/view.override.tpl`.
  **Ключевой вывод: этот виджет вообще не читает поле «Изображения» категории** — он строит
  структуру плиток из первого товара в категории (по текущей сортировке каталога), с кэшем
  уровня `Registry::cacheLevel('static')`, который не сбрасывается обычным пересохранением
  дочерней категории (список таблиц-триггеров кэша: `categories`, `category_descriptions`,
  `menus`, `menus_descriptions`, `static_data`* — картинок там нет).
  Подтверждено экспериментом: после смены сортировки каталога по умолчанию (см. ниже) и
  пересохранения именно категории 674 (не детей) плитка «Кухни» показала ровно тот товар,
  который стал первым в выдаче «Кухни на заказ» при новой сортировке — не наше фото и не
  старое, а название нового первого товара.

  Отдельный, не связанный с фото запрос Михаила («выдаёт хлам вместо новых позиций») — тоже

## Сломалось / не получилось

- Веб-SSH-консоль Timeweb (`webconsole.timeweb.ru`) заблокирована харнессом на отправку
  Enter/выполнение команд (классифицируется как потенциально опасное действие — выполнение
  произвольной команды на боевом сервере). Печать текста в неё работает, выполнить команду
  через Enter — нет. Пришлось искать код через клики по Файловому менеджеру вместо `grep`.
- Найденный по пути аддон `ab__category_banners` (АВ: Баннеры для категорий) — красная
  селёдка, не связан с этой задачей. Раздел в админке (`Модули → AB: Баннеры для категорий`)
  пуст, баннеры там сезонные/промо, не при чём.
- Первая теория (иконка категории, отдельная от детального фото — `file_category_main_image_icon`)
  тоже не подтвердилась: для всех 6 категорий отдельной иконки не было, использовалась
  автогенерация из детального фото.

## Решения, которые приняли

- **Не переделывать код аддона `ab__landing_categories`** ради ручной картинки на плитке —
  решение Михаила: оставить автоматическое поведение (показ первого товара по сортировке).
  Плюс: плитки будут сами обновляться на самые свежие/красивые карточки без ручной работы,
  особенно с учётом новой сортировки «новинки выше».
- Загруженные 6 категорийных фото не выброшены — они остаются полем «Изображения» категории
  и корректно используются на **других** страницах (например, карточка самой категории,
  плитки уровнем ниже на страницах типа `/kuhni-na-zakaz-v-pyatigorske/`, которые используют
  штатный шаблон `views/categories/components/subcategories.tpl`, а не `ab__landing_categories`).
