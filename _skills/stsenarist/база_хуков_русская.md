# База виральных хуков для Reels (1031 шаблон)

Универсальная база для написания цепляющих первых фраз в Reels. Семь категорий с разной механикой удержания внимания. Плейсхолдеры в [квадратных скобках] заменяются под свою нишу и тему.

## Когда какая категория работает

| Категория | Кол-во | Когда использовать |
|---|---|---|
| **EDUCATIONAL** | 487 | Обучающий контент, инструкции, лайфхаки, инсайты |
| **STORYTELLING** | 378 | Личные истории, трансформации, провалы, открытия |
| **MYTH BUSTING** | 58 | Развенчание заблуждений, противоречие популярному мнению |
| **AUTHORITY** | 48 | Подтверждение экспертности, цифры, кейсы трансформации |
| **COMPARISON** | 33 | Сравнения "это vs то", "до и после", альтернативы |
| **DAY IN THE LIFE** | 16 | Демонстрация процесса, рутина, закадровая жизнь |
| **RANDOM** | 11 | Спонтанные, неожиданные хуки вне категорий |

# Дополнение: как пользоваться этой базой

## Универсальная формула хука

Любой хук на русском работает по одной из четырёх механик:

1. **Обещание** — "Сейчас покажу, как [результат]"
2. **Парадокс** — "[Распространённое мнение]? Это миф"
3. **История** — "X лет назад я был [состояние А], сейчас [состояние Б]"
4. **Авторитет/доказательство** — "Я сделал [результат], и вот как"

## Как адаптировать под нишу

Любой хук = шаблон. Меняй плейсхолдеры под свою тему. Один и тот же хук в разных нишах работает по-разному:

- Хук "Кто-то только что выложил X" → AI: золото / Психология: умирает
- Хук "Три вопроса для X" → Психология: золото / AI: слабо
- Хук "Я начал с нуля в X" → Любая ниша работает

## Что НЕ работает (по эмпирике)

- "X% людей не знают" — низкий engagement
- Длинные вопросы в лоб — низкий engagement
- "Если ты до сих пор..." — низкий engagement
- Слишком общие хуки без конкретики

## Что РАБОТАЕТ лучше всего (по эмпирике)

- "Кто-то только что выложил/слил/выпустил X" — высокий engagement
- "Хватит платить за X" — высокий engagement
- "Я научу тебя X за минуту" — высокий engagement
- Конкретное число + время ("3 вопроса за 60 секунд")
- "Steal my X" / "Возьми мою X" — для B2B

## Финальные принципы

1. **Конкретика важнее ёмкости.** "Три вопроса" > "Несколько вопросов"
2. **Глагол первым.** Действие в первой секунде = удержание
3. **Без рекапа в конце.** Концовка должна крючить на следующее видео, не подытоживать
4. **Один эмоциональный пик в видео.** Один CAPS, одна сильная пауза
5. **CTA = кодовое слово или одно простое действие**
