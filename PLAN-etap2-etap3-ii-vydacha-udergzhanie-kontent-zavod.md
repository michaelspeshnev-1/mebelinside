## Что важно знать (факты, не мнения)

1. **`llms.txt` почти никто не читает.** Ahrefs (май 2026, 137 тыс. доменов): 97 % опубликованных файлов получили ноль запросов; Google заявил, что не поддерживает. Файл оставляем (он у нас есть и стоит ничего), но не считаем основным каналом.
2. **ChatGPT-поиск и Copilot берут данные из индекса Bing.** Нет сайта в Bing — ChatGPT не сможет процитировать. Нужны: Bing Webmaster Tools, sitemap, IndexNow. В Bing Webmaster с февраля 2026 есть панель «AI Performance» (сколько раз вас цитировали).
3. **Что ИИ цитирует для локального бизнеса:** по анализу Yext 6,8 млн цитирований — 44 % первичные сайты компаний и 42 % справочники/карточки (оценка вендора). То есть главные рычаги — ваш сайт и ваши карточки в Яндекс/2ГИС/Google/Bing. Одинаковые название, адрес, телефон везде.
4. **Яндекс:** с 07.04.2026 в Яндекс Вебмастере есть отчёт **«Видимость сайта в Алисе AI»** — доля запросов, где вас упомянули источником, примеры запросов, конкуренты по теме. Нужно только добавить сайт и подтвердить права. Практики оптимизации (по обзорам рынка, не официальные): быть в топ-20 обычной выдачи; ответ в первых 1–2 предложениях под заголовком-вопросом; FAQPage/LocalBusiness-разметка; внешние упоминания бренда; живые отзывы. Купить или гарантировать место нельзя.
5. **Свежесть.** Обновлённые страницы цитируются чаще (оценка вендоров: ~6 против ~3,6 цитат).

# ЭТАП 2B. Удержание клиентов (мебель на заказ = редкие дорогие покупки)

Клиент берёт кухню раз в 10–15 лет, поэтому «удержание» здесь = **рекомендации, отзывы, следующая комната, сервис**.

| Метод (мировая практика) | Как адаптировать у нас |
|---|---|
| **Реферальная программа** — для дорогих покупок доверие к рекомендации выше рекламы; просить через 2–4 недели после сдачи, награда обоим | Подарок/скидка на следующий заказ (например подсветка, аксессуар), не деньги; карточка в комплекте с QR |
| **Просьба об отзыве в пик радости** | В день монтажа/через 2 недели: сообщение со ссылкой на Яндекс Карты/2ГИС + QR. Только естественный приток (память проекта: за «залив» блокируют) |
| **Сервисные касания** | 1 мес. («как эксплуатация?»), 6 мес. (бесплатная регулировка фурнитуры), 12 мес., за 1 мес. до конца гарантии (23-й) — каждое = повод вернуться |
| **«Следующая комната»** | Кухня → шкаф-купе/прихожая/гардеробная/детская: сегментное сообщение через 3–6 мес. |
| **Партнёрка для дизайнеров, риелторов, прорабов** | Комиссия/бонус за приведённого клиента; самый сильный повторяющийся канал для заказной мебели |
| **CRM с напоминаниями** | В списке программ на ПК есть Битрикс24 — завести воронку «замер → проект → договор → монтаж → сервис 1/6/12/23» и автозадачи |
| **Гарантийный паспорт с QR** | Уход, регулировки, контакт сервиса; ссылка «оставить отзыв» и «заказать ещё» |
| **Истории объектов (с согласия клиента)** | Фото готового объекта → соцсети и сайт (это же топливо контент-завода, этап 3) |
| **Мягкий ретаргетинг** (Яндекс Метрика/Директ) на тех, кто считал калькулятор | Платные каналы раньше не дали результата (BACKLOG) — только небольшой тест |

Юридически: рассылки — только с согласием (152-ФЗ и ФЗ «О рекламе»); чекбоксы согласия на формах уже сделаны 21.09.
Метрики: число отзывов в месяц, доля заказов «по рекомендации/повторных», ответы на сервисные касания.

# ЭТАП 3. Контент-завод: «бросил фото — всё ушло»

## Диагноз (почему вы теряетесь)

Сегодня есть **три несвязанных места**: (1) бот в GitHub (работает по расписанию), (2) папка `kontent-zavod` с карточками кейсов (руками), (3) ваши ручные действия (ВК-фото, Авито, Яндекс, Instagram через Metricool). Единой «ленты статуса» нет — поэтому не видно, что и куда ушло.

Что бот уже умеет (по `STATUS.md`): каждый день 10:00 МСК публикует пост из контент-плана в Telegram, ВК, MAX, ОК; Авито и Яндекс Бизнес присылает текстом в личку; фото с `#объект` → сразу во все площадки, в т. ч. каруселью. Чего **нет**: описание по фото пишете вы сами; ВК — без фото (групповой токен); Instagram не подключён; нет единого журнала «ушло / без фото / ошибка».

## Целевая схема

1. **Вход:** вы шлёте боту в личку 1–N фото (+ по желанию 3–5 слов: город, материал).
2. **Обработка фото:** авто-яркость и контраст (для «тёмных» кухонь), ресайз под площадки.
3. **Текст:** нейросеть с vision описывает фото, подставляет проверенные факты из `RULES.md` (срок 45–60 дней, замер платный, без выдуманных цен), делает вариант под каждую площадку.
4. **Проверка:** черновик приходит вам в личку, одна кнопка «Ок / правка». (Позже можно включить автопубликацию без подтверждения.)
5. **Публикация:** Telegram, MAX, ВК, ОК — бот напрямую; **Instagram — через Metricool** (нужен профессиональный аккаунт Instagram; API Metricool только на тарифах **Advanced/Custom**; ВК и ОК Metricool не поддерживает — их остаётся публиковать ботом); Авито и Яндекс Бизнес — вручную по готовому пакету (надёжного API нет).
6. **Учёт:** одна таблица/страница: дата · объект · площадка · статус (✓ с фото / ✓ без фото / ✗ ошибка / ждёт вас). Вечером бот присылает **одну сводку** вместо россыпи сообщений.

## Где это «жить»: Claude Code или Cowork?

- **Ядро — GitHub Actions (бот).** Работает без вашего компьютера, 0 ₽ за хостинг, уже работает. Публикации не должны зависеть от того, включён ли ПК.
- **Claude Code (сейчас):** разработка и правки бота, работа с сайтом/админкой, аудиты — то, где нужен браузер и файлы.
- **Cowork:** запланированные задачи выполняются в облаке и не требуют включённого компьютера, но всё, что использует локальные файлы/браузер/ПК, требует открытого приложения Claude. Подходит как «интерфейс» для пакетной подготовки и напоминаний, но **для надёжных ежедневных публикаций хуже, чем бот**.
- Вывод: **публикация — бот, «мозги» — Claude API внутри бота, разработка — Claude Code.** Cowork — по желанию для разборов и сводок.
