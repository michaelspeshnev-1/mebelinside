# Агенты «Мебель Inside» — кто за что и где работает

Обновлено: 2026-10-07. Единый план для всех — `ROADMAP.md`. Память — только этот репозиторий:
любой агент в начале читает `ROADMAP.md` и `STATUS.md`, в конце коммитит и пушит.

| Агент | Чем занят | Где живёт | Как запускается |
|---|---|---|---|
| **Главный** (координатор) | ведёт ROADMAP, раздаёт задачи, правит бота, сливает PR, разбирает сбои | облачный чат Claude Code «Синхронизация чатов и управление задачами» | вы пишете в этот чат |
| **SMM** | посты, рилс, карусели, план бота, Metricool | 1) бот `content-bot` — сам каждый день в 10:00; 2) задача «Контент-завод» — сама по воскресеньям 19:00; 3) `.claude/agents/smm.md` — вызывается из любого чата Claude Code | автоматически + «агент smm, сделай…» |
| **Сайт** | карточки, тексты, посадочные, правки на сайте | локальный чат Claude Code на ПК (встроенный браузер, вход в админку) — сейчас это чат «Агент: Сайт (ПК)» | вы пишете в этот чат на ПК; описание роли — `.claude/agents/sait.md` |
| **SEO** | Вебмастер, Bing/IndexNow, FAQ, Яндекс/2ГИС, мониторинг ИИ-выдачи | `.claude/agents/seo.md`; кабинеты — на ПК; аудит сайта из облака — после разрешения домена | «агент seo, сделай…» в любом чате |

## Claude Code, Cowork или обычный чат?

- **Claude Code** — основной. Облачный (главный чат, задачи по расписанию) работает без вашего ПК;
  локальный на ПК (десктоп-приложение) — для всего, где нужен браузер и файлы с диска.
- **Cowork** — то же ядро; для ваших задач не нужен: расписания уже есть в Claude Code, а всё,
  что требует ПК/браузера, в Cowork тоже работает только при открытом приложении.
- **Обычные чаты claude.ai** — не используем для работы: они не видят репозиторий и забывают
  контекст. Только для быстрых вопросов.

## Правила для всех агентов

1. Начать: `ROADMAP.md` → своя секция, `STATUS.md`, верх `JOURNAL-mebelinside.md`.
2. Один чат на направление, а не на каждую мелочь. Параллельные подзадачи — помощниками внутри чата.
3. После каждого шага: коммит + пуш, строка в журнале, статус задачи в `ROADMAP.md`.
4. Публикации — только через бота (план) и Metricool (черновики); выход в эфир — после «да» Михаила.


## Как называть чаты (решение 07.10 — чтобы не путаться)

Первым символом названия — где работает чат:
- **☁️ Облако:** — Claude Code в облаке (claude.ai/code): тексты, планы, бот, PR. Главный — «☁️ ГЛАВНЫЙ (облако) — пишите сюда».
- **💻 ПК:** — Claude Code на домашнем/рабочем компьютере Михаила со встроенным браузером: админка сайта, Метрика, Вебмастер, Диск.
- **🏢 Офис:** — то же на офисном компьютере (если запускается там).
Михаил пишет только в «☁️ ГЛАВНЫЙ»; агенты-помощники «Главный» запускает и закрывает сам, их чаты открывать не нужно.
Чат «💻 ПК» открывает Михаил (облако не может включить компьютер) — одной фразой: «Выполни ZADANIE-sait-2026-10-07.md по порядку».
