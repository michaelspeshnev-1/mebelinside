## Порядок (от срочного и безопасного к зависящему от других страниц)

**Шаг 0 — бэкап.** Скачать текущий `robots.txt` и `sitemap.xml` в `site-blocks/tech/backup-ГГГГ-ММ-ДД/`, скриншоты меню
(ПК + телефон) и подвала. Закоммитить. Без бэкапа не начинать.

**Шаг 1 — меню (R59, срочно, ~20–40 мин).** `menu-megamenu.md`, шаги 0–3 и проверка 3.2. Подвал (шаг 4) — можно позже,
в этот же заход, если время есть; ссылки на несозданные страницы не ставить.

**Шаг 2 — robots.txt (~15 мин).** `robots-dobavit.txt`.
1. Где править [?]: Веб-сайт → SEO → robots.txt (в CS-Cart 4.x есть редактор robots.txt в разделе SEO — найти в меню
   «Веб-сайт»); если пункта нет — файл `robots.txt` в корне сайта (там же, где `index.php`, `site-blocks/indexnow/README.md` шаг 2)
   через файловый менеджер хостинга.
2. Вставить блок в группу `User-agent: *` и в каждую отдельную группу Yandex/Googlebot (если есть). `Clean-param` — один раз.
3. **Не трогать** `Disallow: /*features_hash=`, `Sitemap:`, группы ИИ-ботов. Пагинацию не закрывать.
4. Canonical (для Google, который Clean-param не читает) [?]: Ctrl+U на категории с `?sort_by=price&sort_order=asc` и с
   `?utm_source=test` — есть ли `<link rel="canonical" href="…без параметров…">`. Если есть — ничего не делать. Если нет —
   записать в журнал как задачу (правка шаблона темы, не в этот заход). На `?page=2` canonical должен вести на саму `?page=2`
   (не на первую) — тоже проверить и записать.
5. Проверка — в конце файла robots (Вебмастер → Анализ robots.txt, список URL «разрешён/запрещён»).

**Шаг 3 — sitemap (~15 мин + ожидание).** `sitemap-dobavit.txt`, раздел 1 (сейчас).
1. Модули → «XML-карта сайта» [?] (название модуля может быть «Google sitemap») → настройки → перегенерировать.
2. Открыть `/sitemap.xml` → Ctrl+F по 3 посадочным (Ессентуки, Кисловодск, Blum). Нет — разобраться, почему модуль не берёт
   страницы (настройки «включать страницы» [?]), записать причину в журнал.
3. Вебмастер и GSC — отправить sitemap заново; IndexNow — `site-blocks/indexnow/README.md`.

**Шаг 4 — 301 (~20 мин).** `redirects-301.md`. Сейчас — только №1 (`contact.html.html`) и №2 (алюминиевый профиль,
сначала перенести товары!). №3 Wilsonart — после создания `/fasady-plastik.html`; №4 дизайнерам — после `/b2b/dizayneram/`.
Каждый 301 проверить `curl -sI` и записать в журнал.

**Шаг 5 — форма и цели Метрики (~1–1,5 ч).** `forma-otpravit-foto.md`. Сначала тестовая форма с файлом (главный [?]),
потом цели в Метрике, потом скрипт, потом проверка `?_ym_debug=1`. Без номера счётчика скрипт ничего не отправляет
(`COUNTER_ID = 0`) — это безопасно, но цели не заработают.

**Шаг 6 — разметка (по мере заливки страниц).** `schema/README.md`: сначала Ctrl+U — что тема уже выводит (BreadcrumbList,
FAQPage, @id организации на главной), потом вставлять. FurnitureStore — вместе с текстом «О компании».

После каждого шага: сброс кэша `/adminmeb.php?cc&ctpl`, проверка на живом сайте, строка в `JOURNAL-mebelinside.md`, коммит.
