# Заливка на сайт — карточки для Claude в Chrome

Каждая карточка — один шаг из [`ZADANIE-sait-2026-10-07.md`](https://github.com/michaelspeshnev-1/mebelinside/blob/main/ZADANIE-sait-2026-10-07.md) (п. 0–19): что сделать в админке, что вставить, как проверить, чего нельзя, какой отчёт написать. Карточки самодостаточные — другие файлы читать не нужно.

## Как запустить

Михаил пишет в боковой панели Claude в Chrome одну фразу:

> Открой https://github.com/michaelspeshnev-1/mebelinside/blob/main/zalivka/README.md, выполняй карточки по порядку, по одной: открой карточку по ссылке, сделай, проверь, напиши мне строку из раздела «Отчёт» и переходи к следующей. Если в карточке что-то непонятно или нужен я — пропусти шаг, напиши об этом в отчёте и иди дальше.

Отчёты Михаил копирует в чат «☁️ ГЛАВНЫЙ» — Главный пишет журнал и ROADMAP.

## Общие правила (действуют во всех карточках)

- Админка: https://mebelinside.ru/adminmeb.php. После каждой правки — сброс кэша https://mebelinside.ru/adminmeb.php?cc&ctpl и проверка в новой вкладке.
- Ничего не удалять — только выключать. 301 — только названные в карточке. «Пользовательские CSS» не трогать.
- Пометка [?] = не проверено: на месте выясни; фразу с [?] в видимый текст сайта не вставляй.
- Карточки 00–04 уже сделаны 08.10 — там только проверка.
