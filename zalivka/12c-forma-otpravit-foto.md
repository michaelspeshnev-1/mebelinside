#### 1. Что видит посетитель

```
Пришлите фото или планировку
Дадим предварительный ориентир по стоимости. Достаточно фото кухни или помещения.

[ Фото или планировка  📎 выбрать файл ]   ← обязательное
[ Имя                                ]      ← обязательное
[ Телефон  +7 (___) ___-__-__        ]      ← обязательное
[        Отправить фото        ]
Нажимая кнопку, вы соглашаетесь с политикой обработки персональных данных (ссылка)

— или напишите в мессенджер —
[WhatsApp] [Telegram] [MAX] [Позвонить]
Отвечаем в рабочее время. Фото используем только для расчёта.
```

Только 3 поля, одна кнопка. Никаких «email», «город», «комментарий» — каждое лишнее поле режет конверсию.
Для B2B (`/b2b/`, дизайнерам) — тот же блок, заголовок «Пришлите ТЗ, чертежи или фото помещения» (`PAGES-b2b-dizayn-drafty.md`).

#### 2. Форма средствами CS-Cart

CS-Cart делает формы модулем **«Конструктор форм»** (Form Builder): страница типа «Форма».

1. Модули → Управление модулями → «Конструктор форм» — включён? [?]
2. Веб-сайт → Страницы → **Добавить форму** [?] (в некоторых версиях — «Добавить страницу» → тип «Форма»).
   - Название: «Отправить фото». SEO-имя: `otpravit-foto` → адрес `/otpravit-foto/` или `/otpravit-foto.html` по ЧПУ [?].
   - Вкладка **«Конструктор форм»**:
     | Поле | Тип в CS-Cart | Обязательное |
     |---|---|---|
     | Фото или планировка | **Файл** [?] | да |
     | Имя | Поле ввода | да |
     | Телефон | Телефон (если есть такой тип) или Поле ввода [?] | да |
   - **E-mail получателя** (поле в настройках формы): почта, которую Михаил читает каждый день [?] — спросить.
   - **Текст после отправки:** «Спасибо! Фото получили. Перезвоним или напишем в рабочее время. Если срочно — +7 928 951-63-42.»
3. **Проверить, умеет ли форма принимать файл** [?] — главный риск. Отправить тестовую заявку с фото 5 МБ с телефона:
   - письмо пришло, файл приложен или есть ссылка на него;
   - фото с iPhone (HEIC) тоже проходит [?];
   - лимит размера: `upload_max_filesize` / `post_max_size` на хостинге [?] — если меньше 10 МБ, попросить хостинг поднять или написать под полем «до N МБ».
   **Если типа «Файл» нет или файл не доходит** — запасной вариант: форма «имя + телефон» + под ней крупно
   «Фото пришлите в WhatsApp / Telegram / MAX» (кнопки ниже). Не ставить сторонние формы без согласования.
4. **Заявки в Telegram** (ARHITEKTURA п. 5.1 «уходит на почту/в Telegram») — средствами CS-Cart из коробки нет [?].
   Сейчас — только на почту. Пересылку почты в Telegram решать отдельно (не в этом пакете).
5. **Антиспам:** если в CS-Cart включена капча (Настройки → Защита от спама / модуль «Защита от спама» [?]) — включить для этой формы
   невидимую капчу; не ставить капчу «с картинками» — режет конверсию.
6. **Политика персональных данных:** ссылка на существующую страницу политики [?] (найти в подвале или Веб-сайт → Страницы).
   Если страницы нет — сообщить Михаилу, форму без неё не публиковать (152-ФЗ).
7. Вывод формы на других страницах: на главной, посадочной кухонь, расчётах, `/b2b/` — блок **«Форма»** [?] в макете
   (Дизайн → Макеты → вкладка страницы → добавить блок → тип «Форма»/«Страница» с этой формой). Если тема не умеет
   выводить форму блоком — на этих страницах ставим блок с мессенджерами (`blok-otpravit-foto.html`) + кнопку
   «Отправить фото» со ссылкой на `/otpravit-foto/`.
8. После отправки CS-Cart обычно открывает ту же страницу с параметром `sent=Y` [?] — проверить адрес в строке браузера
   после тестовой заявки; от этого зависит цель «форма» (п. 4.3).

## Проверка

- `/otpravit-foto/` (или `.html`) открывается, форма отправляется, письмо с фото пришло.
- Перед проверкой сбросить кэш: https://mebelinside.ru/adminmeb.php?cc&ctpl, страницу открывать в новой вкладке.

## Нельзя

- Не ставить форму в шапку/меню, пока тестовая заявка не дошла.
- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
