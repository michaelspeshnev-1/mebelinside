# 23-b2b-foto-keysy · Фото B2B-кейсов из Drive: отбор, сжатие, заливка, alt

Задание: B2B-кейсы 10.10 (агент «Тексты») · ~40 мин · Кто: агент «Сайт» на ПК (нужны Drive и админка) · Админка: https://mebelinside.ru/adminmeb.php

Тексты кейсов — `PROEKTY-keysy-teksty.md`, разделы 6a–6c (карточки 16g, 16h, 16i); страницы — карточки 17c, 17d.
Описание фото — `MEDIA-b2b-obekty.md`. Делать после того, как страницы кейсов созданы (или вместе с ними).

## Что сделать

1. **Скачать.** Drive, папка «фото мебель» (аккаунт Михаила). Файл по id открывается так: `https://drive.google.com/file/d/<id>/view`
   → «Скачать» (оригинал, не превью). Серии ищутся поиском Drive по имени (`IMG_20240727_14`, `IMG_20221001_18`, `IMG_20201231_01`).
   Скачивать в отдельную папку на ПК, по подпапке на кейс: `restoran-loft/`, `pekarnya-kafe/`, `torgovoe/`.
2. **Отобрать 4–6 фото на кейс** по таблицам ниже. Отбраковывать:
   - **вывеску, логотип или название заведения/магазина** (если логотип в углу — кадрировать; если в центре — не брать);
   - **людей** (в том числе отражения в зеркале и стекле);
   - читаемые ценники, этикетки, документы, номера машин в окне;
   - смаз, сильный завал горизонта, мебель в плёнке как главное фото (тумба ресторана — только как дополнительное).
3. **Сжать:** ширина **1600 px** (по длинной стороне для вертикальных — высота не больше 1600), JPEG качество 80–85, убрать EXIF
   (там дата и, возможно, геометка). Пример на ПК (Python + Pillow), скрипт держать вне папки с фото,
   запуск: `python resize1600.py <папка-кейса>/*.jpg`:
   ```python
   import sys
   from PIL import Image, ImageOps
   for f in sys.argv[1:]:
       im = ImageOps.exif_transpose(Image.open(f)).convert("RGB")  # поворот по EXIF, EXIF дальше не сохраняется
       im.thumbnail((1600, 1600))
       im.save(f.rsplit(".", 1)[0] + "-1600.jpg", "JPEG", quality=82, optimize=True)
   ```
   Имена файлов — латиницей по порядку: `1.jpg`, `2.jpg`, … (как в разметке других кейсов).
4. **Залить** через файловый менеджер редактора CS-Cart (кнопка картинки → «Обзор») в папку
   `images/proekty/<slug>/`: `restoran-loft/`, `pekarnya-kafe/`, `torgovoe-oborudovanie/`.
5. **Вставить в кейсы** (16g, 16h, 16i): блок фото в порядке таблицы, у каждого `alt` — из таблицы ниже, `loading="lazy"` (кроме первого).
   Первое фото — в JSON-LD `image` кейса (реальные URL вместо заглушек).
6. **Вставить в страницы раздела**: в `<img src="">` блока «Проекты» — первое фото кейса (17c: ресторан и пекарня; 17d: торговое).
   `alt` в HTML уже стоит — не менять.
7. Сбросить кэш https://mebelinside.ru/adminmeb.php?cc&ctpl, открыть страницы в новой вкладке.

## Проверка

- На каждой странице кейса 4–6 фото (пекарня — не меньше 2), все открываются, ширина 1600 px, вес одного — до ~400 КБ.
- Ни на одном фото нет вывески, логотипа, названия заведения/магазина, людей, ценников.
- `alt` у всех фото — из таблиц выше; в 17c/17d у карточек «Проекты» есть картинка.
- Ctrl+U на кейсе → `"image"` в JSON-LD с реальными URL.

## Нельзя

- Не ставить `1wI-T_dkHYZHTDTdIzsWQwSGAiqnt3NqJ` и любые кадры с вывеской.
- Не брать видео на страницы (VID_* — для рилс), не перерисовывать фото ИИ, не ставить визуализации.
- Не подписывать фото названием заведения, городом или адресом.
