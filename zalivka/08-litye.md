# 08-litye · Убрать «литьё столешниц» и «Woodtec» с главной

Задание: п. 8, R22 · ~10–20 мин · Админка: https://mebelinside.ru/adminmeb.php

## Что сделать

1. Открыть главную, Ctrl+F «литьё» и «Woodtec». Если 0 совпадений (старый блок выключен в карточке 05) — пункт закрыт, ничего не делать, сразу отчёт.
2. Если совпадения есть — правка файла через панель Timeweb → «Файловый менеджер» (Путь Б ниже). Перед правкой — «Копировать» файл рядом с именем `head_scripts.post.tpl.bak-2026-10-ДД-chrome`.
3. Править только 4 фразы из таблицы «Что менять». Сохранить, сбросить кэш.
4. Если в редакторе вместо кириллицы видны `\u04..`-коды и найти фразу не получается — остановиться и написать в отчёте «нужен Claude Code», файл не сохранять.

## Что вставить

Копия из [`TZ-litye-na-glavnoy.md`](https://github.com/michaelspeshnev-1/mebelinside/blob/main/TZ-litye-na-glavnoy.md):

#### 1. Где лежит

```
~/public_html/design/themes/abt__unitheme2/templates/addons/abt__unitheme2/hooks/index/head_scripts.post.tpl
```

571 строка, ~69 КБ. Это весь самописный слой `mi-`: CSS, JS, калькулятор, JSON-LD,
блоки главной. Нужный текст — на **строке 258**.

Доступ: панель Timeweb → **SSH-консоль** (или Файловый менеджер). FTP не нужен.

**Важно:** в админке CS-Cart есть файл с таким же именем по пути
`templates/hooks/index/head_scripts.post.tpl` — **это не он**. Правка того файла
на сайт не влияет (проверено). Живой — только тот, что в `templates/addons/`.

#### 3. Что менять

Текст хранится **в юникод-эскейпах** внутри JS-строки. Два места:

| Что | Сейчас | Надо |
|---|---|---|
| Подпись под фото | `Литьё столешниц` | `Акриловый камень` |
| Абзац под заголовком | `…присадка, кромка и литьё столешниц из искусственного камня.` | `…присадка, кромка, обработка акрилового камня и HPL-пластика.` |
| Там же | `станки ЧПУ Woodtec` | `станки с ЧПУ` |
| Подпись под фото 2 | `Раскрой на ЧПУ Woodtec` | `Раскрой на ЧПУ` |

##### Путь Б — файловый менеджер Timeweb (проще и безопаснее)

Панель → **Файловый менеджер** → пройти по пути из п.1 → открыть файл в редакторе →
найти строку 258 → править текст обычной кириллицей прямо в браузере.
Редактор работает с UTF-8 нормально, проблемы консоли там нет.

**Это рекомендуемый путь.** Консоль хороша для поиска, но не для ввода русского текста.

## Проверка

- На главной Ctrl+F «литьё», «Woodtec», «, HPL-» — 0.
- Главная открывается целиком, калькулятор и блоки на месте.
- Перед проверкой сбросить кэш: https://mebelinside.ru/adminmeb.php?cc&ctpl, страницу открывать в новой вкладке.

## Нельзя

- Не трогать файл с тем же именем в `templates/hooks/index/` — он не тот.
- Ничего, кроме 4 фраз, в файле не менять.
- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
