## Шаг 0. Выгрузить полные списки (обязательно, 2 мин)

Скрипт аудита печатает **только первые 25 строк** каждого списка, а `audit.csv` в git нет. Поэтому в репозитории есть 25 из 55 страниц без мета и нет адресов дублей и «30–45». На ПК, в папке репозитория:

```
python3 tools/seo_audit.py https://mebelinside.ru      # если audit.csv от 08.10 не сохранился
python3 tools/audit_export.py audit.csv > audit-spiski.md
```

В `audit-spiski.md` будут полные списки: все страницы без title/description, все H1≠1, группы дублей с адресами, страницы с «30–45». Его закоммитить в корень репо (`audit-spiski.md`, 20–40 КБ) — облачный агент SEO допишет тексты для недостающих URL.

## Общие правила заливки

- **Как CS-Cart выводит H1:** H1 = поле «Название» у категории, страницы и товара. Title = вкладка «SEO» → «Заголовок страницы». Description = «SEO» → «Мета-описание».
- **Поле «SEO-имя» (адрес) не трогать.** Если при смене «Названия» CS-Cart предложит обновить SEO-имя — отказаться. URL не меняем, 301 не делаем.
- Если «Название» стоит в меню/хлебных крошках и меняет их нежелательно — найти отдельное поле «Заголовок H1» (есть не во всех версиях) [?]; если его нет — менять «Название», меню сверить после.
- После каждой правки — сброс кэша https://mebelinside.ru/adminmeb.php?cc&ctpl, страница в новой вкладке, Ctrl+U → поиск `<h1` (должно быть ровно 1) и `<title>`.
- Ничего не удалять — только выключать. «Пользовательские CSS» не трогать.

**HTML для главной** (H1 + строка фактов; стили внутри, CSS темы не трогаем):

```html
<div class="mi-hero-h1" style="text-align:center;margin:24px 0 8px">
  <h1 style="font-size:30px;line-height:1.2;margin:0 0 8px">Мебель на заказ для дома и бизнеса</h1>
  <p style="margin:0;color:#555">Свой цех в Пятигорске с 2009 года · 1000+ заказов · срок 45–60 дней в договоре · гарантия 2 года</p>
</div>
```

Если в макете главной уже есть блок с заголовком-приветствием (выводится как `<h2>`/`<div>`), можно вместо нового блока поменять его тег на H1 — но тогда один H1, не два.

### `/materialy.html`: 8 лишних H1 → H2

Аудит отдаёт только число H1 (9), сами тексты — в `audit.csv`/исходном коде. Как найти и что оставить:

1. Открыть https://mebelinside.ru/materialy.html → Ctrl+U → поиск `<h1` → выписать 9 текстов в отчёт.
2. **Оставить H1** — первый, заголовок страницы. Его текст: **Материалы для кухонь и мебели** (как в [14a-materialy-hub](https://github.com/michaelspeshnev-1/mebelinside/blob/main/zalivka/14a-materialy-hub.md)). Если первый H1 — «Материалы» без продолжения, переименовать «Название» страницы в «Материалы для кухонь и мебели».
3. **Остальные 8 → H2.** Ожидаемо это заголовки разделов по материалам [?] — «МДФ эмаль», «Пластик», «АГТ», «ЛДСП», «МДФ плёнка», «Шпон», «Массив», «Столешницы» или названия коллекций декоров. Правка: Веб-сайт → Страницы → «Материалы» → описание → «Исходный код» → заменить `<h1` на `<h2` и `</h1>` на `</h2>` во всём описании (теги в шаблоне страницы не трогать). Если H1 сидят не в описании, а в HTML-блоках макета — менять тег в каждом блоке так же.
4. Если 9 H1 выводит PHP-галерея (вне CS-Cart) — файлы галереи **не редактировать**, записать в отчёт «H1 из галереи, нужен разработчик».

Проверка: Ctrl+U → `<h1` — ровно 1 совпадение.

## R27. «30–45 дней» → «45–60 дней» (23 страницы)

Адресов в репозитории нет (только в `audit.csv`) — список даёт шаг 0 (раздел «30–45» в `audit-spiski.md`). По аудиту это: карточки кухонь, `/proizvodstvo.html` и 1 гардеробная.

**Замены (дословно):**

| Было | Стало | Где |
|---|---|---|
| «30–45 дней», «30-45 дней», «от 30 до 45 дней» | **«45–60 дней»** | все страницы, кроме ниже |
| то же — в карточке/категории с фасадами **AGT** или **Эвоглосс** | **«от 30 дней»** | только AGT/Эвоглосс |
| то же — в карточке из **массива** | **«60–80 дней»** | массив |
| «срок 30–45 дней» в Title/Description | «срок 45–60 дней в договоре» | SEO-вкладка |

Где править: Каталог → Товары (или Категории) → карточка → «Описание» (Ctrl+F «30») и вкладка «SEO» (Title/Description) — фраза бывает в обоих. Для `/proizvodstvo.html` — Веб-сайт → Страницы. Если фраза в **сквозном блоке** (видна на всех страницах сразу) — править блок один раз в Дизайн → Макеты и записать в отчёт.

Проверка: после правки повторить https://yandex.ru/search/?text=site%3Amebelinside.ru+%2230-45+дней%22 через 1–2 недели; сразу — Ctrl+F «30» на каждой исправленной странице. Исправленные URL отправить в IndexNow (карточка [04-indexnow](https://github.com/michaelspeshnev-1/mebelinside/blob/main/zalivka/04-indexnow.md)).

## R65. `/hi-max.html` — не отвечает (код 0)

Что это: страница бренда **LG HI-MACS** (акриловый камень для столешниц) — вариант характеристики «Бренд». На неё ведёт ссылка со страницы столешниц (`MATERIALY-2-stranitsy-teksty.md`, `/hi-max.html` в списке брендов) — **страница нужна, удалять и убирать её нельзя.**

**Рекомендация — починить, не убирать:**

1. Открыть https://mebelinside.ru/hi-max.html в новой вкладке 2–3 раза.
   - **Открывается** → таймаут был разовым: ничего не менять, при следующем аудите проверить снова. В отчёт: «открывается за N с».
   - **Долго (>10 с) или ошибка** → шаг 2.
2. Товары → Характеристики → «Бренд» → «Варианты» → HI-MACS: статус «Вкл», картинка-логотип не гигантская (если файл >1 МБ — заменить на сжатый). Заполнить «Описание» текстом из `BRANDS-opisaniya-i-podval.md` → раздел «LG HI-MACS» и Title/Description из [22a](https://github.com/michaelspeshnev-1/mebelinside/blob/main/zalivka/22a-meta-brendy.md). Сброс кэша, открыть снова.
3. **Всё ещё не открывается** → проверить в Яндекс Вебмастере (Индексирование → Статистика обхода / Страницы в поиске) и Метрике (Отчёты → Страницы входа, фильтр `hi-max`) трафик за 3 месяца:
   - **есть трафик или страница в поиске** → не трогать sitemap, передать Михаилу: «нужен разработчик/хостинг, страница с трафиком падает»;
   - **трафика 0 и в поиске нет** → временно исключить из sitemap (Веб-сайт → Карта сайта / настройки модуля «Google sitemap» → исключить вариант бренда [?]). Ссылку со страницы столешниц оставить, страницу не выключать — после починки вернуть в sitemap.
4. 301 с `/hi-max.html` на другой адрес — **не делать** без «да» Михаила.
