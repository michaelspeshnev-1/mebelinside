## Что известно и чего нет

Аудит 08.10 нашёл **55 страниц без title/description**, но скрипт напечатал только первые 25 адресов. Здесь:

- **А** — 3 страницы из аудита + 2 калькулятора (у них title есть, но с «Квиз»/без города — по `ARHITEKTURA-sayta-v2.md` заменить);
- **Б** — 22 бренда техники и моек из аудита + `rainford`, `falmec`, `elica` (по списку «тонких» страниц — те же шаблонные страницы брендов, ~149 слов);
- **В** — бренды материалов и фурнитуры (их 17 логотипов на сайте; вероятно, это часть оставшихся ~27 из 55 [?]).

**Оставшиеся адреса выгружает ПК-агент:** `python3 tools/audit_export.py audit.csv > audit-spiski.md` (см. карточку 22, шаг 0) → коммит в репо → облачный агент SEO допишет строки. Пока строк нет — страницу из `audit-spiski.md`, которой нет в таблицах, пропустить и записать в отчёт.

## Как заливать

- **Бренды (Б, В):** Товары → Характеристики → «Бренд» → вкладка «Варианты» → раскрыть бренд → поля «Заголовок страницы» (Title) и «Мета-описание» (Description) [?] — если у варианта нет SEO-полей, они на вкладке «SEO» варианта или в Веб-сайт → SEO → «Правила SEO» [?]. «Название» варианта (= H1) **не менять**: в колонке H1 указано текущее имя для поиска. Описание бренда (видимый текст) — из `BRANDS-opisaniya-i-podval.md`, раздел 2 (для техники и моек текстов пока нет — страница остаётся «тонкой», это следующий шаг).
- **Категории (А):** Каталог → Категории → категория → вкладка «SEO».
- **Страницы (А):** Веб-сайт → Страницы → страница → вкладка «SEO».
- Если поле **уже заполнено** — не перезаписывать, кроме калькуляторов (там заменить).
- Строки с [?] в URL — адрес не проверен: найти бренд по имени; если страницы нет — пропустить.
- После каждых 5–10 правок — сброс кэша https://mebelinside.ru/adminmeb.php?cc&ctpl и проверка одной страницы: Ctrl+U → `<title>` и `name="description"`.
- Title — до 65 символов, Description — до 160 (посчитано в колонках «Симв.»). Пометку « [?]» в имени бренда в Title не вставлять.
