# 06a-glavnaya-bloki · Главная: тексты блоков

Задание: п. 6, R19 (+ п. 13) · ~30 мин · Админка: https://mebelinside.ru/adminmeb.php

## Что сделать

1. Дизайн → Макеты → «Главная». Скриншот до правки.
2. Для каждого блока ниже, где есть ```html```: найти на главной блок с тем же смыслом; если он HTML-блок — заменить содержимое; если нет — создать «HTML-блок» в нужном месте (порядок — по номерам 1.2 → 1.9).
3. Блоки без HTML (1.1, 1.3, 1.4, 1.6, 1.8) — это указания: 1.4 — поменять ссылки плиток стилей с `?features_hash=` на адреса из 1.4; 1.1, 1.3, 1.6 — выполнить только то, для чего не нужно выбирать фото (фото и отзывы — в отчёт «нужен Михаил»).
4. 1.9 «Заявка» — блок `site-blocks/blok-otpravit-foto.html` (весь код — в карточке 07), если его ещё нет на главной.
5. Title/Description/H1 главной — не отсюда, а из карточки 10.
6. Не больше 8 смысловых блоков на главной (мера Михаила 07.10): если блок дублирует уже стоящий — заменить, а не добавлять второй.

HTML вставлять в режиме «Исходный код» редактора (кнопка `</>`/«HTML»): визуальный редактор CS-Cart ломает `<script>`. Строки «Длины…», «Ключи…», «Примечание…» и текст между блоками — подсказки для тебя, на сайт их не вставлять.

## Проверка

- Блоки «Что мы делаем», «Почему», «Как мы работаем», «Пришлите фото» видны на главной, ссылки открываются (200).

- Ctrl+F «литьё» — 0.
- Перед проверкой сбросить кэш: https://mebelinside.ru/adminmeb.php?cc&ctpl, страницу открывать в новой вкладке.

## Нельзя

- Слайдер баннеров не трогать (решение Михаила 07.10: оставляем).
- Второй FAQ на главную не ставить.
- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
