# 00a. Меню: «Детская мебель» → в конец «Для бизнеса» (решение Михаила 08.10)

**Где:** админка → Дизайн → Меню (или Вкладки/Блоки — где правили п. 0).

1. Убрать «Детская мебель» из подпунктов «Мебели для дома» и из начала меню (если там есть).
2. Добавить **последним** пунктом в «Для бизнеса»: **«Школы и детские сады»** → ссылка на текущую
   категорию детской мебели (относительная, без `?features_hash=`).
3. Если в подвале есть колонка «Для бизнеса» — тот же пункт последним.
4. На главную (слайдер, блоки) детскую **не** ставить.
5. Посадочную `/b2b/shkoly-detskie-sady/` не создавать — сделаем позже.

**Проверка:** на живом сайте «Детская мебель» не видна в «Мебели для дома»; в «Для бизнеса» последним —
«Школы и детские сады», ссылка открывается (200). Отчёт — одной строкой Главному.
