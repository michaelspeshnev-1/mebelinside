## Что сделать

1. Открыть https://mebelinside.ru/agt.html — если страница уже есть (200), не создавать вторую, а заменить ей описание.
2. Посмотреть, как устроены другие страницы брендов (например, https://mebelinside.ru/blum.html): это вариант характеристики «Бренд» (Каталог → Характеристики → Бренд) или страница (Веб-сайт → Страницы). Создать AGT тем же способом.
3. Название (= H1): AGT; SEO-имя: `agt`; описание — HTML ниже; Title — из блока ниже.
4. Ссылку `agt-uv-lak/` в тексте проверить (200); ссылку на `/fasady-agt.html` оставить — страница появится в карточке 14d (до того — временно убрать ссылку и вернуть после 14d).
5. Новый адрес — в индекс: Модули → «Карта сайта для Yandex и Google» → «Обновить»; затем открыть в новой вкладке `https://yandex.com/indexnow?url=<новый адрес>&key=07507e4412dc8eb2f5a64fc34ce9f5b7` (пустая страница или «OK» — принято).

HTML вставлять в режиме «Исходный код» редактора (кнопка `</>`/«HTML»): визуальный редактор CS-Cart ломает `<script>`. Строки «Длины…», «Ключи…», «Примечание…» и текст между блоками — подсказки для тебя, на сайт их не вставлять.

## Нельзя

- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
