# 02-audit-30-45 · Живой аудит вручную: остатки «30–45 дней»

Задание: п. 2, R33/R27 · ~20 мин · Админка: https://mebelinside.ru/adminmeb.php

> **Статус:** скрипт `tools/seo_audit.py` в Chrome не запустить — его прогонит Главный или Claude Code. Здесь — только ручной поиск.

## Что сделать

1. Открыть в новой вкладке: https://yandex.ru/search/?text=site%3Amebelinside.ru+%2230-45+дней%22
2. Затем: https://yandex.ru/search/?text=site%3Amebelinside.ru+%2230%E2%80%9345+дней%22 (с длинным тире).
3. Выписать все адреса из выдачи (первые 3 страницы).
4. Открыть 3–5 из них и Ctrl+F «30» — подтвердить, что фраза ещё на странице (выдача могла устареть).
5. Ничего не исправлять в этой карточке — только список. Сквозной блок преимуществ (если фраза в нём) — отметить отдельно.

## Проверка

- Есть список адресов с «30–45 дней», про каждый — «на странице есть / уже нет».
- Перед проверкой сбросить кэш: https://mebelinside.ru/adminmeb.php?cc&ctpl, страницу открывать в новой вкладке.

## Нельзя

- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
