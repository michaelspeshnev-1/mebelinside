# 22b-dubli-title-h1 · Дубли Title/H1 и 10 карточек «Кухня МДФ + пленка» (R64)

Задание: R64 · часть 3 из 3 карточки [22](https://github.com/michaelspeshnev-1/mebelinside/blob/main/zalivka/22-meta-h1-audit.md) · ~40 мин · Админка: https://mebelinside.ru/adminmeb.php

## Что известно

Аудит 08.10 дал **тексты** дублей, но не адреса (они в `audit.csv`, его нет в git). Адреса каждой группы — в `audit-spiski.md` (карточка 22, шаг 0: `python3 tools/audit_export.py audit.csv`). Ниже для каждой группы: какой адрес оставляет текущий текст, что получает второй.

**Правило «какой главный»:** текущий Title/H1 оставляет страница, которая (1) стоит в главном меню, (2) при равенстве — у которой больше товаров/текста. Второй получает текст из колонки «Второй». Обе страницы остаются — **ничего не удалять, адреса не менять, 301 не делать** (если страницы — полные копии, записать в отчёт «кандидат на склейку» — решает Михаил).

Где править: категория — Каталог → Категории → «SEO» (Title) и «Название» (H1); страница — Веб-сайт → Страницы; товар — Каталог → Товары → карточка. **SEO-имя не трогать** — при смене «Названия» отказаться от обновления адреса.

## 3. 10 карточек «Кухня на заказ - Кухня МДФ + пленка» (+2 «Кухня на заказ -»)

Названий этих товаров, цветов и адресов в аудите нет — различать по **фото и характеристикам карточки**. Найти: Каталог → Товары → поиск «МДФ + пленка» (и «Кухня на заказ -»).

**Шаблон (заполнить для каждой карточки):**

- **H1 = «Название» товара:** `Кухня МДФ плёнка {цвет}, {планировка}` — напр. «Кухня МДФ плёнка белый глянец, угловая».
- **Title:** `{Планировка} кухня МДФ плёнка {цвет} — Мебель Inside` (≤65 симв.) — напр. «Угловая кухня МДФ плёнка светло-серый мат — Мебель Inside» (57).
- **Description:** `Кухня с фасадами МДФ в плёнке ПВХ: {цвет}, {планировка}{, деталь}. Сделаем по вашим размерам в цехе в Пятигорске.` (≤160) — напр. «Кухня с фасадами МДФ в плёнке ПВХ: светло-серый матовый, угловая с барной стойкой, современный стиль. Сделаем по вашим размерам в цехе в Пятигорске.» (148).

## Проверка

- Повторный аудит или `audit-spiski.md` из нового `audit.csv`: разделы «Дубли title» и «Дубли h1» — 0 групп (или только «кандидаты на склейку» с пометкой).

## Нельзя

- Менять SEO-имя (URL), склеивать дубли 301 без «да» Михаила, удалять карточки/категории.
- Цены (кроме купе МДФ от 37 000 ₽/п.м), имена клиентов, «бесплатный замер» без условия, «льём столешницы», Wilsonart.
