# 11d-materialy-galereya · `/materialy/`: можно ли вставить HTML (проверка)

Задание: п. 11, решение Михаила 07.10 п. 1 · ~10 мин · Админка: https://mebelinside.ru/adminmeb.php

## Что сделать

1. Открыть https://mebelinside.ru/materialy/ — это PHP-галерея декоров (вне CS-Cart).
2. Поискать в админке: Веб-сайт → Страницы → поиск «materialy»; Дизайн → Макеты — есть ли отдельный макет/страница для неё.
3. Если в админке есть поле, куда вставить HTML над галереей, — схема «хаб = `/materialy/`».
4. Если нет — схема «хаб = новая страница CS-Cart `/materialy-dlya-mebeli.html`», галерея остаётся «Справочником декоров». Ничего в галерее не править.
5. Результат записать в отчёт — по нему делается карточка 14a.

## Проверка

- Решение принято: А) HTML в `/materialy/` или Б) хаб на `/materialy-dlya-mebeli.html`.
- Перед проверкой сбросить кэш: https://mebelinside.ru/adminmeb.php?cc&ctpl, страницу открывать в новой вкладке.

## Нельзя

- Файлы галереи `/materialy/` не редактировать.
- Ничего не удалять (страницы, категории, блоки, товары, файлы) — ненужное выключать (статус «Выключено»/«Скрыто»).
- 301-редирект — только если он прямо назван в этой карточке как решённый Михаилом; любой другой — сначала «да» Михаила.
- Не трогать «Пользовательские CSS» (Дизайн → Редактор тем) — однажды это дало белый экран сайта.
- Не выдумывать: предложение с пометкой [?] в видимом тексте не вставлять (убрать целиком); HTML-комментарии `<!-- … -->` на сайте не видны — их можно оставить.
