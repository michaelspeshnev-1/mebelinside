# Мебель Inside — инструкция для Claude

Облачные сессии обрываются и начинаются с нуля. Память проекта — только в этом репозитории.

1. **Первым делом прочитай `STATUS.md`** — там текущее состояние и что делать дальше.
   Потом верх `JOURNAL-mebelinside.md` и нужный раздел `BACKLOG.md`.
2. Соцсети публикует бот из репозитория `michaelspeshnev-1/content-bot` (GitHub Actions, 10:00 МСК:
   Telegram, ВК, MAX, ОК; тексты для Авито и Яндекса — в личку владельцу). Не предлагай ручную
   публикацию и не подключай Telegram заново — сначала проверь бота.
3. **Перед концом сессии** (и после каждого заметного шага): обнови `STATUS.md`, добавь строку в
   `JOURNAL-mebelinside.md`, закоммить и запушь. Всё незапушенное теряется.
4. Общаемся по-русски, коротко и по делу.
