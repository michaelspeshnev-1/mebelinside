# Инструкции для каждого чата Claude

Проект — сайт и соцсети «Мебель Inside» (mebelinside.ru, CS-Cart).
Облачные сессии обрываются и начинаются с нуля. Память проекта — только в этом репозитории.

## В начале любого чата
1. Прочитай `ROADMAP.md` — ЕДИНСТВЕННЫЙ план (задачи R1…, кто отвечает, статусы). `TASKS-board.md`, `BACKLOG.md`,
   `ROADMAP-site.md`, `PLAN-…` — архив/справка.
2. Прочитай `AGENTS.md` — какой агент за что отвечает и где работает; `STATUS.md` — текущее состояние.
3. Прочитай верх `JOURNAL-mebelinside.md` и нужный раздел `BACKLOG.md` / `ROADMAP-site.md`.
4. Не переделывай то, что уже отмечено сделанным в журнале.

## Соцсети
Регламент всех публикаций (посты и рилс) — `KONTENT-ZAVOD.md`.
Публикует бот из репозитория `michaelspeshnev-1/content-bot` (GitHub Actions, 10:00 МСК:
Telegram, ВК, MAX, ОК; тексты для Авито и Яндекса — в личку Михаилу; пост про объект —
фото с подписью `#объект` боту в личку). Не предлагай ручную публикацию по площадкам и не
подключай Telegram заново — сначала проверь бота (README, `state.json`, запуски Actions).

## В конце (и после каждого заметного шага)
1. Добавь одну строку сверху в `JOURNAL-mebelinside.md` (формат указан в файле).
2. Обнови статус своей задачи в `ROADMAP.md` и, если изменилось состояние, `STATUS.md`.
3. Подробности — в `PROGRESS-ГГГГ-ММ-ДД-тема.md` по шаблону из `templates/`.
4. Закоммить и запушь — всё незапушенное теряется вместе с контейнером.

## Браузер
Облачная сессия не видит Chrome/браузер компьютера Михаила. Если задача требует
админки сайта или соцсетей — поставь в доске статус 🟡 «нужен браузер» и подготовь
всё, что можно, файлами (тексты, SQL, инструкции), чтобы локальная сессия только залила.
