## Как работает 301 в CS-Cart — что проверить сначала

- Редиректы задаются в модуле SEO: **Веб-сайт → SEO → 301-редиректы** (в англ. админке Website → SEO → SEO redirects).
  [?] Точное название пункта в этой версии CS-Cart — посмотреть в меню «Веб-сайт»; если пункта нет — Модули → SEO → проверить, что модуль включён.
- Поле «Старый URL» — путь от корня **без домена** (`/contact.html.html`), «Новый URL» — выбрать объект (страница/категория)
  или вписать путь. [?] какие варианты даёт форма — смотреть на месте.
- **Редирект срабатывает только когда по старому адресу ничего нет.** Пока страница/категория живая и отдаёт 200,
  CS-Cart показывает её, а не редирект. [?] Проверить на п. 1 первым делом: добавить редирект → открыть адрес → если
  всё ещё 200, значит сначала нужно убрать источник (см. ниже).
- Настройка **Модули → SEO → «Создавать 301-редирект при смене SEO-имени»** [?] (если есть и включена) — при переименовании
  SEO-имени CS-Cart сам добавит редирект. Удобно для п. 1.

## Пошагово

### 1. `/contact.html.html` → `/contact.html`

1. Найти, откуда берётся адрес: Веб-сайт → Страницы → поиск «контакт». Скорее всего, есть страница с SEO-именем `contact.html`
   (CS-Cart сам дописывает `.html` → получается `.html.html`). [?] Одна это страница с двумя адресами или две разные.
2. Если **две страницы**: у дубля статус «Скрыто» (не удалять до проверки) → добавить 301 `/contact.html.html` → `/contact.html`.
3. Если **одна страница** с SEO-именем `contact.html` и вторым адресом `/contact.html` из другого места [?]: не трогать
   рабочий адрес `/contact.html` — разобраться, какой из двух адресов задан в SEO-имени, и только тогда решать.
4. На главной ссылку «Посмотреть на карте» поменять на `/contact.html` (Дизайн → Макеты → главная → блок с этой ссылкой [?]).
5. Убрать `/contact.html.html` из `sitemap.xml` (если он там) и из `/sitemap.html`.
6. Проверка: `curl -sI https://mebelinside.ru/contact.html.html` → `301` и `Location: https://mebelinside.ru/contact.html`;
   `/contact.html` → `200`.

### 2. Категория «Пластик в алюминиевом профиле» → «Кухни с фасадами МДФ пластик»

1. Каталог → Категории → «Пластик в алюминиевом профиле». Записать число товаров.
2. **Товары перенести** (Каталог → Товары → фильтр по категории → выделить все → «Редактировать выбранные» → категория):
   основная категория — «Кухни с фасадами МДФ пластик» или другая подходящая. **Удаление категории в CS-Cart удаляет товары,
   у которых она единственная** — поэтому категорию не удалять, а ставить статус «Выключено».
   [?] Если товары — именно рамочные фасады со стеклом (витрины), согласовать с Михаилом, куда их.
3. Статус категории → «Выключено». Убрать её из меню, из плиток категории кухонь и из блока «Из чего делаем кухни» на
   страницах Ессентуки (id 81) и Кисловодск (id 82) — там стоит ссылка «Кухни с алюминиевой рамкой» (`pages_payload.json`).
4. Добавить 301 (старый URL → новый) по таблице.
5. Проверка: старый адрес → `301` на новый; новый → `200`; ссылок на старый адрес на сайте нет
   (`grep` по выгрузке `tools/seo_audit.py` или поиск по сайту «alyuminievom»).

### 3. `/wilsonart.html` → `/fasady-plastik.html`

1. Сначала создать `/fasady-plastik.html` (тексты — `MATERIALY-stranitsy-teksty.md`), проверить 200.
2. Найти, что такое `/wilsonart.html`: страница бренда — это вариант характеристики «Бренд» (Каталог → Характеристики →
   Бренд → Wilsonart) или обычная страница (Веб-сайт → Страницы). [?] смотреть на месте.
3. Снять с сайта: статус «Выключено»/«Скрыто»; убрать логотип и ссылку из подвала, блока логотипов брендов,
   описаний товаров (поиск «Wilsonart» по товарам — Каталог → Товары → поиск по описанию [?]).
   У товаров, где Wilsonart указан в характеристике «Бренд», — значение убрать или заменить на фактического производителя [?] (спросить Михаила).
4. Добавить 301 `/wilsonart.html` → `/fasady-plastik.html`.
5. Проверка: `curl -sI …/wilsonart.html` → `301` на `/fasady-plastik.html`.

### 4. `/dizayneram-i-arhitektoram.html` → `/b2b/dizayneram/`

1. Создать страницу «Дизайнерам и архитекторам» внутри B2B, перенести текст (`PAGES-b2b-dizayn-drafty.md`,
   `PARTNERKA-dizaynery-rieltory.md`). [?] Что такое `/b2b/` в CS-Cart — страница или категория; итоговый адрес
   дочерней страницы будет `/b2b/dizayneram/` или `/b2b/dizayneram.html` — зависит от настроек ЧПУ (Модули → SEO →
   «Вид ЧПУ для страниц»). Редирект ставить **на фактический адрес**, а в журнал записать, какой он получился.
2. Проверить: новая страница 200, форма «Расчёт по ТЗ» работает.
3. Старую страницу — статус «Скрыто» (не удалять), добавить 301.
4. Поменять ссылки на старый адрес: меню, подвал, хаб `/b2b/`, тексты кейсов (`PROEKTY-keysy-teksty.md` ссылается на оба адреса).
5. Проверка: старый адрес → `301` на новый.
