# IndexNow для mebelinside.ru (R39)

IndexNow — способ сразу сказать поисковикам «эта страница изменилась». Его принимают Bing (а через индекс
Bing — ChatGPT-поиск и Copilot), Яндекс, Seznam, Naver. Один запрос на `api.indexnow.org` передаётся всем
участникам; скрипт на всякий случай шлёт и напрямую в Яндекс.

- Ключ: `07507e4412dc8eb2f5a64fc34ce9f5b7` (сгенерирован 07.10.2026, публичный по смыслу протокола — не секрет).
- Ключ-файл: `site-blocks/indexnow/07507e4412dc8eb2f5a64fc34ce9f5b7.txt` (внутри — только ключ, без перевода строки).
- Скрипт: `tools/indexnow_ping.py` (Python 3, без установки библиотек).

## Шаг 1. Один раз: залить ключ-файл в корень сайта (нужен браузер, ~5 минут)

1. Timeweb → панель хостинга → «Файловый менеджер».
2. Открыть корневую папку сайта mebelinside.ru — ту, где лежат `index.php`, `config.local.php`, `robots.txt`
   (обычно `mebelinside.ru/public_html/`).
3. «Загрузить» → выбрать файл `07507e4412dc8eb2f5a64fc34ce9f5b7.txt` из этой папки репозитория.
   Имя файла не менять. Ничего больше в корне не трогать.
4. Проверка в браузере: открыть `https://mebelinside.ru/07507e4412dc8eb2f5a64fc34ce9f5b7.txt` — должна
   показаться строка `07507e4412dc8eb2f5a64fc34ce9f5b7`. Или на ПК:
   `python3 tools/indexnow_ping.py --check-key` → «код 200; содержимое совпадает».
5. Если открывается страница 404 CS-Cart — файл попал не в ту папку (не рядом с `index.php`).

Откат: удалить этот файл в Файловом менеджере. На работу сайта он не влияет.

## Шаг 2. Первая отправка — весь sitemap

```bash
python3 tools/indexnow_ping.py --sitemap https://mebelinside.ru/sitemap.xml --dry-run   # посмотреть
python3 tools/indexnow_ping.py --sitemap https://mebelinside.ru/sitemap.xml             # отправить
```

Ожидаемо: `OK https://api.indexnow.org/indexnow: код 200` (или 202 — ключ ещё проверяется, это нормально)
и то же для `yandex.com`. Весь sitemap отправлять **один раз**, дальше — только изменённые страницы.

## Шаг 3. После каждой правки на сайте (1 минута)

1. Записать изменённые адреса в файл, например `indexnow-urls.txt` (по одному в строке, `#` — комментарий):
   ```
   # 07.10 — FAQ и блок производства на главной
   https://mebelinside.ru/
   https://mebelinside.ru/mebel-dlya-doma-ru/kuhni/kuhni-na-zakaz-v-pyatigorske/
   ```
2. Отправить:
   ```bash
   python3 tools/indexnow_ping.py --urls-file indexnow-urls.txt
   ```
   Или без файла: `python3 tools/indexnow_ping.py https://mebelinside.ru/ https://mebelinside.ru/b2b/`.
3. Строку «IndexNow: N адресов, код 200» добавить в отчёт сессии (`PROGRESS-…md`).

Что отправлять: новые страницы, изменённые тексты/цены/фото, удалённые страницы (чтобы быстрее выпали).
Не отправлять одно и то же много раз в день — получите `429`.

## Коды ответа

| Код | Что значит | Что делать |
|---|---|---|
| 200 | принято | ничего |
| 202 | принято, ключ проверяется | ничего, через сутки будет 200 |
| 400 | неверный запрос | прислать вывод скрипта в главный чат |
| 403 | ключ не найден на сайте | проверить шаг 1 (`--check-key`) |
| 422 | адреса не того домена | адреса только `https://mebelinside.ru/…` |
| 429 | слишком часто | повторить завтра |

## Где смотреть результат

- Bing Webmaster Tools → IndexNow (после R38): какие адреса пришли.
- Яндекс Вебмастер → Индексирование → «Переобход страниц» / отчёт IndexNow (после R35).

## Ключ сменить

`python3 -c "import secrets;print(secrets.token_hex(16))"` → создать `<новый ключ>.txt` с ключом внутри,
залить в корень, старый файл удалить, файл в этой папке заменить (скрипт берёт единственный `.txt`-ключ отсюда).
