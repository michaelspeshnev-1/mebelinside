# КОНТЕНТ-ЗАВОД — как выходят все посты и рилс

Один пульт: чат «Синхронизация чатов и управление задачами» (главный) + воскресная задача
«Контент-завод». Всё остальное им подчиняется. Обновлено: 2026-10-05 (правило замера уточнено).

**Что доносим и какие рубрики** — `CENNOST-i-rubriki.md` (главная мысль «кухня без сюрпризов», 5 обещаний,
доли рубрик). Каждый пост и рилс относится к одной рубрике и одному обещанию.

## Где лежит план и медиа

- **План постов — только `content-bot/content-plan.csv`** (PR в репозиторий бота). Google-таблица
  «Контент-план_Mebel_Inside_2026» в Drive пустая (только заголовок, с 22.09 не менялась) — её не
  используем. Если в секретах `content-bot` задан `SHEET_CSV_URL`, его надо удалить: иначе бот читает
  таблицу, а не файл (проверить: GitHub → content-bot → Settings → Secrets and variables → Actions).
- **Фото и видео** — Google Drive, папка «фото мебель» с подпапками по категориям; опись — `MEDIA-biblioteka.md`.
  Видео теперь приоритет перед фото.

## Недельный цикл

1. **Воскресенье 19:00 МСК — задача «Контент-завод»** (Routine): читает `STATUS.md`, этот файл,
   `content-plan.csv`; ищет свежие новости отрасли за 7 дней; готовит строки плана на неделю и
   открывает PR «План на неделю ДД.ММ» в `content-bot`; готовит версии под Instagram (пост +
   сценарий рилс) черновиками «на проверку» в Metricool; обновляет `STATUS.md` + `JOURNAL`;
   присылает push.
2. **Михаил:** сливает PR = «да» на публикацию в TG/ВК/MAX/ОК; в Metricool одобряет черновики;
   снимает/присылает видео для рилс по сценарию.
3. **Каждый день 10:00** — бот публикует; в личку — Авито/Яндекс.
4. **Главный чат** — правки бота, разбор сбоев, внеплановые посты, аудит раз в неделю.

## Рилс

Сценарии и подход — `REELS-stsenarii-i-plan.md` (3 готовых сценария), навык сценариста —
`_skills/stsenarist/`. Видео — только свои ролики (не репосты). CTA, шаблоны ответов в директ и
ссылки с UTM — `CTA-reels.md`.

Видео снимает Михаил (телефон, вертикально 9:16, 7–30 с, без лица — руки, фасады, открывание
ящиков, свет). Завод даёт: сценарий по кадрам, текст на экран, подпись, хэштеги. Видео
кладётся в Metricool (или присылается в главный чат ссылкой) → черновик Reels «на проверку».
Бот публикует видео (с 05.10): колонка `video_url` в плане (ссылка на mp4 до 20 МБ или file_id)
или видео с подписью `#объект …` боту в личку. Telegram и MAX — само видео; ВК и ОК — текст со
ссылкой на видео в канале (групповые токены не дают грузить видео). Видео без `#объект` бот
вернёт с file_id — его можно вписать в `video_url`. Подробности — README `content-bot`.

## Правила текстов (жёсткие)

- Цены — только подтверждённые: шкафы-купе из МДФ от 37 000 ₽/п.м. Других цифр не писать.
- Замер: **бесплатный после предварительного просчёта в шоуруме**; выезд без просчёта — 1500 ₽
  Пятигорск, 2000 ₽ Ессентуки/Кисловодск/Минводы/Железноводск, вычитается из заказа. 3D-проект
  бесплатно. Не писать просто «бесплатный замер» без условия про шоурум (подтверждено Михаилом 05.10).
- Свой цех с 2009, гарантия 2 года, доставка и подъём по факту; столешницы не льём.
- Срок изготовления 45–60 дней.
- Без имён клиентов и адресов — только город. Факты по объекту — только подтверждённые Михаилом.
- Ссылка: `https://mebelinside.ru/rasschitat-stoimost.html?utm_source={площадка}&utm_medium=post&utm_campaign={метка}`; в Авито и Яндекс — без ссылки, только mebelinside.ru.

## Синхронизация (после каждого шага)

- Любое изменение — коммит и пуш сразу, не в конце дня. Контейнер облачного чата удаляется.
- Посты для бота — только через `content-plan.csv` (PR в `content-bot`), не руками в соцсетях.
- После каждой сессии: строка в `JOURNAL-mebelinside.md`, `STATUS.md` перезаписан, строка в `TASKS-board.md`.
- Instagram публикуется только через Metricool, чтобы был виден в одном календаре (в сентябре
  пост 20.09 ушёл дважды — 12:50 и 13:40).

## Известные проблемы

- GitHub пропускает cron-запуски (05.10 не было ни одного) → добавлены запасные запуски и защита от дублей.
- ВК: групповой токен не грузит фото (`1051`), посты в ВК уходят без фото.
- Видео во ВК и ОК не загружается (нужны пользовательский токен ВК и право VIDEO_CONTENT в ОК) — уходит ссылка на канал.
