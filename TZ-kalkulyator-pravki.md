**Путь в админке:** `Дизайн → Шаблоны → abt__unitheme2 → templates → hooks → index`
**Где именно:** блок разметки калькулятора, встречается **дважды** — в панели
«По площади» (`#p-area`) и в панели «По погонным метрам» (`#p-meters`).

## 1. Что сейчас не так

| Что | Сейчас | Почему неверно |
|---|---|---|
| Кнопка | «Заказать бесплатный замер» | замер теперь платный |
| Срок | «Срок изготовления: 30–60 дней» | реальный 45–60 |
| Подпись | «Замер и дизайн-проект — бесплатно» | бесплатен только проект |
| Подпись сверху | «точная стоимость — после бесплатного замера» | то же |
| Действие кнопки | `callback()` → `alert()` с телефонами на десктопе, `tel:` на мобильном | заявка не фиксируется нигде, расчёт не сохраняется |

Последний пункт — главный. Человек досчитал бюджет, увидел цифру, нажал кнопку —
и получил окно с телефонами. Ни лида, ни данных о том, что он считал.

## 3. Замена функции

**Было:**

```javascript
function callback(){
  if(/Mobi|Android|iPhone/i.test(navigator.userAgent)){
    window.location.href='tel:+79289516342';
  } else {
    alert('Свяжитесь с нами:\n\nТел.: +7 928 951-63-42\n…');
  }
}
```

**Стало:**

```javascript
function toQuiz(){
  try{
    var q = parent.document.querySelector('[id^="quiz-go-show-"]');
    if(q){
      q.scrollIntoView({behavior:'smooth', block:'start'});
      return;
    }
  }catch(e){}
  try{ parent.location.href = '/napisat-nam.html'; }
  catch(e){ window.top.location.href = '/napisat-nam.html'; }
}
```

Что делает: если на странице есть квиз QuizGo — плавно прокручивает к нему.
Если квиза нет (как на `/rasschitat-stoimost.html`) — отправляет на форму заявки.

## 4. Почему именно так

Квиз **уже собирает заявки** и работает — это единственный работающий сборщик лидов
на этих страницах. Но он стоит на 1757-м пикселе, под калькулятором высотой 1755 px,
то есть его не видит никто, кто не проскроллил калькулятор целиком.

Эта правка решает обе проблемы разом: калькулятор перестаёт быть тупиком,
а квиз получает трафик именно в тот момент, когда человек уже увидел свою цифру
и хочет уточнить. Ничего нового строить не нужно.

Альтернатива — встроить в калькулятор собственную форму с отправкой в CS-Cart.
Это дольше и дублирует квиз. Если захотите — сделаем отдельной задачей.

## 5. Мелочь там же

В подписи под заголовком калькулятора:

- **было:** «предварительный расчёт. точная стоимость — после бесплатного замера»
- **стало:** «предварительный расчёт. точная стоимость — после замера»

## 6. Чего эта правка не делает

- **Не меняет цены.** Эконом 55–75, Оптимум 75–140, Премиум 140–280 тыс ₽/п.м
  остаются как есть — они совпадают с вашей реальной медианой 93 333 ₽/м.
- **Не трогает заголовок страницы** «Расчет стоимости кухни - Квиз», хотя калькулятор
  считает мебель для всей квартиры, а не кухню. Отдельный вопрос.
- **Не решает** то, что калькулятор не сохраняет расчёт. Человек уходит в квиз
  и вводит данные заново. Чтобы передавать сумму в квиз, нужен доступ к настройкам
  QuizGo — это следующий шаг, если решите.

## 7. Перед сохранением

Файл рендерится в `<head>` **на всех страницах сайта**. Ошибка в нём положит вёрстку
везде сразу. Поэтому:

1. Скопировать текущее содержимое файла в резервную копию до правки.
2. После сохранения проверить главную, карточку товара и страницу расчёта.
3. Помнить про расхождение файла и отдаваемой страницы (см. раздел 10 отчёта):
   если правка не применится сразу — дело в кэше шаблонов, а не в коде.
