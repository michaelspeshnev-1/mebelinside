## Как всё устроено (коротко)

| Что | Где | Кто публикует |
|---|---|---|
| Контент-бот | репозиторий `michaelspeshnev-1/content-bot`, GitHub Actions (`poster.yml`) | сам, по расписанию |
| Контент-план | Google-таблица (секрет `SHEET_CSV_URL`), копия — `content-bot/content-plan.csv` | — |
| Telegram-канал, ВК, MAX, ОК | бот, **каждый день в 10:00 МСК** по строке плана на сегодня | бот |
| Авито, Яндекс Бизнес | бот присылает готовый текст в личку в 10:00 | Михаил вручную, потом `/done` боту |
| Пост про конкретный объект | фото + подпись `#объект …` боту в личку → уходит сразу во все площадки | бот |
| Блог сайта | tg2blog (`/public_html/tgbot/` на хостинге) слушает TG-канал | сам |
| Сайт (CS-Cart, Timeweb) | правки только из сессии с браузером (облачной сессии сайт недоступен) | вручную |

**Отдельно подключать Telegram (Composio, OAuth и т. п.) не нужно** — токены бота уже лежат
в секретах GitHub-репозитория `content-bot`. Публиковать «вручную на 5 площадках» тоже не нужно:
4 площадки закрывает бот, 2 (Авито, Яндекс) — текст приходит в личку.

## Правило для каждой сессии

1. Начать с этого файла, затем `JOURNAL-mebelinside.md` (верх) и `BACKLOG.md`.

   а не придумывать ручную публикацию.

   Незакоммиченное пропадает — контейнер облачной сессии удаляется.
