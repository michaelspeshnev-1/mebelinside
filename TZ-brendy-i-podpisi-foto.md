## Шаг 0. Подготовка (5–10 минут, до входа в админку)

Локальная сессия видит сайт снаружи, поэтому сначала **собрать списки скриптом**,
а в админку идти уже с готовыми id. Скрипт — Python 3, без библиотек. Сохранить как
`scan_brand_alt.py` в любую папку и запустить `python scan_brand_alt.py`.

```python
# Скан живого сайта: (1) бренды в тексте карточек, (2) матрасные alt/title у фото.
import re, urllib.request, json, html

SITE = "https://mebelinside.ru"
BRANDS = ["Blum", "Hettich", "GTV", "Boyard", "DTC", "MAKMART", "EGGER", "Lamarty",
          "Увадрев", "EvoGloss", "Arpa", "Wilsonart", "Slotex", "Staron", "HI-MACS",
          "Grandex", "Renner"]
# маркеры матрасных названий: новые (27.09) + старые (12.09)
MATTRESS = re.compile(r"Lux Mix|Foam|Soft|Strong|Hard|Holl|Komfort|Optima|Standart|"
                      r"Real Sleep|Real Soft|TFK|S500|Mix\b|Latex|Cocos|Кокос|Spring",
                      re.I)

def get(url):
    req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    return urllib.request.urlopen(req, timeout=30).read().decode("utf-8", "ignore")

sm = get(SITE + "/sitemap.xml")
urls = re.findall(r"<loc>(.*?)</loc>", sm)
# если sitemap — индекс из нескольких файлов, развернуть
if any(u.endswith(".xml") for u in urls):
    urls = [u2 for u in urls if u.endswith(".xml") for u2 in re.findall(r"<loc>(.*?)</loc>", get(u))]

brands, alts = [], []
for u in urls:
    try:
        p = get(u)
    except Exception as e:
        print("ERR", u, e); continue
    pid = re.search(r'name="product_id" value="(\d+)"', p) or re.search(r"product_id=(\d+)", p)
    pid = pid.group(1) if pid else ""
    title = re.search(r"<h1[^>]*>(.*?)</h1>", p, re.S)
    title = html.unescape(re.sub("<[^>]+>", "", title.group(1))).strip() if title else ""
    # (1) бренды — только на страницах товаров (есть кнопка/форма товара)
    if pid and "product_main_info" in p or 'itemtype="http://schema.org/Product"' in p:
        text = re.sub("<[^>]+>", " ", p)
        found = [b for b in BRANDS if re.search(r"\b" + re.escape(b) + r"\b", text, re.I)]
        if found:
            brands.append({"url": u, "id": pid, "name": title, "brands": found})
    # (2) матрасные alt/title у картинок + id товара по det_img_<id>
    for m in re.finditer(r"<img[^>]+>", p):
        tag = m.group(0)
        for attr in ("alt", "title"):
            v = re.search(attr + r'="([^"]*)"', tag)
            if v and MATTRESS.search(v.group(1)):
                img_pid = re.search(r"det_img_(\d+)", tag)
                alts.append({"page": u, "attr": attr, "value": v.group(1),
                             "product_id": img_pid.group(1) if img_pid else pid,
                             "src": (re.search(r'src="([^"]+)"', tag) or [None, ""])[1]})

json.dump(brands, open("brands_found.json", "w", encoding="utf-8"), ensure_ascii=False, indent=1)
json.dump(alts, open("mattress_alts.json", "w", encoding="utf-8"), ensure_ascii=False, indent=1)
print("карточек с брендом:", len(brands))
print("матрасных alt/title:", len(alts), "уникальных товаров:",
      len({a["product_id"] for a in alts if a["product_id"]}))
```

**Что проверить после запуска:**
- `brands_found.json` — должно быть около 64 карточек. Если сильно меньше —
  проверить, что скрипт распознаёт страницы товаров (условие про `product_main_info`),
  и при необходимости убрать это условие (тогда в список попадут и категории —
  отфильтровать вручную по URL).
- `mattress_alts.json` — у маркеров `Soft|Strong|Hard|Mix` бывают ложные срабатывания
  («Soft-close», «Hard-coat» в описании фурнитуры). Смотреть глазами на `value`:
  нужны только названия матрасов.
- Если скрипт не собирает `product_id` у фото — открыть `src` картинки и найти товар
  через админку по названию карточки, на странице которой нашлось фото.

Если скрипт запускать не хочется — ручной путь для каждого шага описан ниже.

4. Проверить 2–3 карточки глазами. Если что-то пошло не так — импортировать бэкап обратно.

## Шаг 2. Подписи фото «от матрасов» в «Кухнях» и «Шкафах» (задача №4)

### Вероятная причина (по опыту 11–12.09)

1. Сайт раньше был каталогом матрасов. Карточки кухонь/шкафов, скорее всего, делали
   **клонированием** старых матрасных карточек (или загружали фото в них) — CS-Cart при
   клонировании копирует и подписи изображений. Название и описание переписали,
   а подписи фото — нет.
2. 12.09 чистили по маркерам `Komfort/Optima/Standart/Real Sleep/Real Soft/TFK/S500` —
   **«Lux Mix», «Foam», «Light Foam», «Soft», «Strong» в тот скан не входили**, поэтому
   эти товары остались. Это уже четвёртое место с матрасными подписями
   (11.09 — логотипы брендов и блог, 12.09 — 37 товаров, теперь — эти).
3. Список 37 товаров от 12.09 — это фото из виджета «Наши последние работы».
   Сейчас проблема видна в листингах категорий «Кухни»/«Шкафы», т. е. другие товары.

### Где хранится подпись

- В CS-Cart подпись фото — поле **«Альтернативный текст» (Alt-текст)** у каждого
  изображения товара: карточка товара → вкладка «Общее» → блок **«Изображения»** →
  кликнуть по фото → раскрываются поля «Alt-текст» у главного и у всех
  дополнительных фото.
- Этот же текст CS-Cart выводит и как `title` (всплывающая подсказка, подпись в
  увеличенном просмотре), поэтому правка одного поля лечит и alt, и title.
- Проверять **все** фото товара — главное и дополнительные: у дополнительных часто
  остаётся своё матрасное название.
- Если подпись осталась, а в поле пусто — посмотреть, не стоит ли фото товара
  из общего пула (одна картинка у нескольких товаров) и не выводит ли тема
  название файла; тогда записать id и не ломать — отдельный разбор.

### Как найти затронутые товары

**Скриптом** — `mattress_alts.json` из шага 0 (список `product_id` + плохое значение).

**Вручную**, если без скрипта:
1. Открыть `https://mebelinside.ru/kuhni/` (и все страницы пагинации, и подкатегории),
   затем «Шкафы» и их подкатегории.
2. В браузере: Ctrl+U (исходный код) → Ctrl+F: `Lux Mix`, `Foam`, `Soft`, `Strong`,
   `Hard`, `Holl`, `Mix`.
3. Рядом с найденным `alt="…"` — `id="det_img_<число>"`: число = product_id.
   Если его нет — кликнуть по карточке, id взять из админки поиском по названию.
4. Записать в таблицу ниже.

### Что писать вместо (шаблон alt)

Правило 12.09 (не менять): **alt = реальное «Название» товара из карточки**, без
сочинённых описаний того, что на фото.

- Главное фото: `<Название товара>` — например `Кухня Ника МДФ эмаль`.
- Дополнительные фото: `<Название товара> — фото 2`, `… — фото 3` (чтобы alt не дублировались).
- Без слов «купить», «недорого», без списков ключевиков, до ~100 символов.
- Если название товара само «матрасное» или пустое — не выдумывать, записать id
  в «Открытые вопросы» для Михаила.

Порядок на каждый товар (проверен ×37 12.09):
`/adminmeb.php?dispatch=products.update&product_id=<id>` → прочитать «Название» →
блок «Изображения» → кликнуть по фото → вписать alt во все фото → свежий скриншот →
«Сохранить» → «Изменения были сохранены».
Не нажимать «URL» в загрузчике картинок: он открывает `prompt()` и вешает браузер
(лечится повторным открытием страницы).
